# 设计116c 结果（开发1，d116）

## 结论：三个目标同时达不到，**数值没改**，请设计定
- 照顺序降伤害，atk6 能到 90%+，但 atk5 也跟着涨到 50% 左右；再加血压 atk5，atk6 又掉到 80% 上下。
- 所有组合里 **atk6 和 atk5 的胜率差都只有 40～48 个百分点**，目标要差 55 以上（≥ 90 和 < 35），只动这三个伤害和血量拉不开。
- 原因（从数据看）：atk6 输的局多是 3 分钟狂暴（死的时间中位 150～180 秒）；atk5 输的是中途被打死（中位 130 秒左右）。降伤害两边一起变活，加血两边一起变慢。
- d116 上保持 **血 120000 / 机炮 0.35 / 电弧 0.3 / 火 0.15**（116a 的数），只做了第 2 条护盾说明。

   - A：血 120000 / 0.35（现在）：atk6 82、def6 96、atk5 34 —— atk5 达标，atk6 差 8。
