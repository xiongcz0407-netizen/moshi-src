## 1. 石柱阵：变长 + 眩晕
- 波数：前半血 3 波、半血后 4 波（原来 2 / 3）；石柱在地上留 **2 秒**（原来 1 秒）。
- 被石柱打中：照旧扣血，再**眩晕 1 秒**：不能走、不能开枪、不能放技能（包括翻滚）。
  - 头顶飘「眩晕」，星星绕头转，身子左右晃；
  - 左上角状态写「眩晕 0.8」这样的倒计时。
- **防连控**：眩晕结束后 1.5 秒内不会再眩晕，伤害照吃。
- 震荡弹照样能打断石柱阵。

## 2. 滚石改全场
- 读条 **1.6 秒**，施法条写「全场滚石——躲到岩石后面！」。
  - 地上整片发红，每个掩体南边一块**绿色安全区**（掩体宽、往南 3 米）。
  - 读完以后一排大石头（全宽，每 2.2 米一块）从北往南滚，速度 **18**。
- 石头碰到掩体就碎在掩体前面（尘土、碎石），**掩体不坏**。
- 判定：石头滚到主角那一行时，主角不在任何掩体的影子里、也不在翻滚无敌里，就扣血（照原来 rollK）+ **禁锢 1 秒**。
  - 禁锢：不能走，能开枪、能放技能；**翻滚能解除**。
  - 头顶飘「禁锢」，脚下一圈碎石把脚埋住；状态栏写「禁锢 0.x」。
- **保证有地方躲**：放之前真掩体不到 2 个，就先从天上掉石头补到 2 个，落在离主角 4～5 米、跑得到的地方，落地有尘土和震屏。
- 原来铁轨两条道那套去掉了。名字改成「全场滚石」：副本面板技能说明、施法条、help 都改了；半血说明去掉了「滚石 3 条」。

## 3. 禁锢后接快速横扫
- 被滚石禁锢 0.1 秒后：BOSS 取消手上的动作，**跳到主角身边**（离主角 2.2 米，跳 0.35 秒，离地约 2 米的弧线，起跳、落地都有尘土，落地震屏）。
- 落地马上「石拳横扫（快！）」，蓄力 **0.45 秒**；范围照平时，伤害 × comboK（现在是 1，没调）。
- 0.1 + 0.35 + 0.45 = 0.9 秒 < 禁锢 1 秒：**不翻滚一定被扫到**。被禁锢后马上翻滚（解除禁锢 + 无敌）就躲得开（fbtest 验过）。
- 只有被滚石禁锢才会触发。

## 4. fbsim
- 两种机器人都会：
  - 滚石时跑进绿色安全区；石头已经滚到跟前、还没躲进去时，就翻滚用无敌躲这一下；
  - 被禁锢后翻滚：走位好 0.1 秒后，走位一般 0.35 秒后。
- 机器人原来那套「预警快到了来不及就翻滚」，对全场滚石不用了：这一招要等石头真的滚到时翻才有用。
- **问题：打得慢了**。躲在掩体后面、石柱留 2 秒，都会挡子弹。子弹被挡从 3% 涨到 8%，全攻击走位好的通关中位从 155 秒变成 164 秒。血量还是 125000 时，偏防御走位好只有 60% 能在 3 分钟内打完。
- **所以第 3 关血量 125000 → 116000**。文档里能调的是伤害系数，但这次掉的是时间，调伤害没用，只能动血量。106 也是这样调的。请设计确认。

**第 3 关（血量 116000，100 局）**
| 装备 | 走位好 | 走位一般 | 目标 |
|---|---|---|---|
| 全攻击 | **94%**，中位 154.5 秒，必吃伤害最多 67% | **48%** | ≥ 90% ✓；25～50% ✓ |
| 偏防御 | **98%**，中位 164.8 秒 | **86%** | ≥ 95% ✓；≥ 70% ✓ |
| 2 件史诗 3 星 | **44%**，中位 174.8 秒 | — | < 30% ✗ |
| tank（站着不躲） | none / e3x2 / xiong / xiongL / 拾荒者 4 件 6★ 都是 0/30 | — | ✓ |

- **要设计看**：2 件史诗 3 星 44%，没达到 < 30%。偏防御 ≥ 95%（3 分钟内）和 2 件史诗 3 星 < 30%，这次靠血量调不到一起：
  - 125000：偏防御走位好 60%（不达标）；
  - 120000：偏防御走位好 80%（不达标）；
  - 116000：偏防御走位好 98%，但 2 件史诗 3 星 44%。
  - 想两条都达标，可以让临时石柱不挡子弹（只挡路），把打得慢那部分补回来；或者加强 2 件史诗 3 星这一身吃得到的东西。请设计定。
- **每局被控制几次**（100 局平均）：
  | | 被眩晕 | 被禁锢 | 被连招扫中 |
  |---|---|---|---|
  | 全攻击走位好 | 0.00 | 0.03 | 0.02 |
  | 全攻击走位一般 | 0.05 | 0.05 | 0.05 |
  | 偏防御走位好 | 0.01 | 0.03 | 0.01 |
  | 偏防御走位一般 | 0.01 | 0.05 | 0.03 |
  - 机器人看得到所有预警、照最优路线跑，基本不吃控制，所以次数很低。真人会多吃不少，等用户手机上试。
