# 设计92a：毒囊酸液喷吐读条慢一点、技能之间留 2～3 秒 —— 结果（V8.11 → V8.21）

版本：**V8.21**（APP_V 821）。存档格式没变。
截图：`美术/检查截图/1024_设计92/92_酸液喷吐读条中_844`（读条 0.8 / 1.3 秒那一刻）

## 1. 读条变慢
- `spitWarn` 0.8 → **1.3 秒**，狂暴后 ×0.7 是 **0.91 秒**。fbsim 里实测喷吐预警就是这两个数。
- 喷吐动画是按读条时间缩放的（`setAnim('spit', 喷出那一帧 / dur)`），张嘴、喷出照样对在预警结束那一刻。

## 2. 任意两个技能之间至少空 2.5 秒（狂暴 2 秒）
- 新加 `TX.calm: 2.5`、`TX.calmRage: 2`。
- 每个技能（喷吐、毒弹、爆裂、拍地、上涌）的硬直结束（被打断的话是眩晕结束）开始算安静时间。
- 安静时间没过完，什么技能都不放，大技能到点了也先等。安静时毒囊照旧看着玩家、站着喘气。
- 喷吐的条件：离下一个大技能还剩的时间要大于「喷吐读条 + 0.45 秒硬直 + 安静时间」，不够这一轮就不插喷吐。
  - 普通：1.3 + 0.45 + 2.5 = 4.25 秒；
  - 狂暴：0.91 + 0.45 + 2 = 3.36 秒。

### ⚠ 有一处跟文档不一样，请你定
- **照文档原样做（方案 A），喷吐会一次都不放。**
  - 大技能的间隔（`gap` 7 秒，狂暴 5.5 秒）是从开始放技能就开始倒数的。
  - 一个大技能放完（读条约 2～3 秒 + 硬直）再安静 2.5 秒，剩下只有 1～2 秒，永远不够插一个喷吐要的 4.25 秒。
- **我用的是方案 B**：大技能的间隔只在毒囊闲着（含安静时间）的时候倒数，放技能、硬直的时候不走。
  - 这样节奏变成：大技能 → 安静 2.5 秒 → 喷吐 → 安静 2.5 秒 → 大技能。
  - 别的技能的读条、伤害、出招顺序都没变；但大技能之间整体拉长了，所以每局放的次数变少。
- 两个方案都跑了 fbsim，数字在下面。要换成方案 A，或者想让大技能更勤一点（比如把 `gap` 调短），告诉我。
