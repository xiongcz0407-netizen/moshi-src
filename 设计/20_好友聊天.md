# 20 好友和聊天 —— 设计稿（用户 10-15 定，待确认）

用户定的：
- 用 Supabase（免费版）做好友和聊天，存档照旧放 GitHub。
- 入口：顶部右上角「i」旁边加一个「好友」图标，有新消息亮红点和数字。
- 加好友：输入对方用户名发申请，对方点「同意」才是好友，好友之间才能发消息。
- 好友列表：显示在线 / 不在线（不写「几分钟前」），还有店名和超市等级。
- 点好友能看他的「名片」：名字、店名、超市等级、在不在线。
- 聊天记录：每个好友只留最近 100 条。

## 一、界面
- 「好友」面板分三页：
  - 「好友」：每个好友一行：绿点（在线）/ 灰点（不在线）、名字、店名、超市几级，有未读消息的写数字。点一行进聊天；右边「名片」按钮看名片。
  - 「申请」：别人发来的好友申请，「同意」/「拒绝」；我发出去还没回的写「等对方同意」。有新申请时这一页标签上亮红点。
  - 「加好友」：输入用户名 →「发申请」。找不到这个人、已经是好友、已经申请过，都直接写出来。
- 聊天：像微信一样，左边对方、右边自己，最下面输入框 +「发送」。一条最多 100 个字，只能发文字。
- 名片：头像（角色头像）、名字、店名、超市几级、在线 / 不在线。可以「删好友」（会确认一次）。
- 顶部「好友」图标：有没读的消息或新申请就亮红点，写总数。

## 二、在线、收消息
- 开着游戏时每分钟报一次「我在线」；2 分钟没报就算不在线。
- 收消息：开着聊天窗口时每 5 秒查一次，平时每 30 秒查一次（不用一直连着，省流量）。
- 断网、连不上 Supabase：好友图标变灰，点开写「连不上好友服务器，稍后再试」，不影响玩游戏。

## 三、账号（技术）
- 不用另外注册：用游戏的用户名 + 6 位口令，在 Supabase 自动建一个对应的账号（第一次打开好友面板时自动建，玩家看不到）。
- 只有登录了云存档的人能用好友（本机存档、离线模式不能用）。
- 要你在 Supabase 后台改一个设置：Authentication → Sign In / Providers → Email 里关掉「Confirm email」（不用发验证邮件）。
- 数据库建表的 SQL 我写好，你在 Supabase 的 SQL Editor 里贴进去点一次 Run。

## 四、数据（技术）
- profiles：每人一行 —— 名字（不能重名）、店名、超市等级、最后在线时间。所有登录的人都能看（搜名字要用），只能改自己的。
- friends：好友关系 —— 谁申请的、申请谁、等对方同意 / 已是好友。只能看跟自己有关的；只有被申请的人能「同意」；两边都能删。
- messages：消息 —— 谁发的、发给谁、内容、时间、读没读。只能看自己发的和发给自己的；只有已经是好友才能发；每对好友超过 100 条自动删最早的。
- 权限都用数据库自带的行级权限（RLS），游戏里的公开 key 只能做上面这些事，看不到别人的聊天。

## 六、改名（用户 10-15 问）
- 好友之间认的是账号里的编号，不是名字：改什么名字都不会把好友关系弄丢。
- 店名：在「设置 → 外观、店名」里改了，马上同步到好友那边（好友列表、名片里显示新店名）。
- 用户名：游戏里本来就改不了（云存档账号、好友账号都是用用户名算出来的）。以后真要做「改用户名」，要同时迁移云存档账号和好友账号，到时再单独设计。

- 账号邮箱：m + 用户名哈希前 24 位 @moshi-game.com，密码由用户名 + 口令算出来；不发邮件。
