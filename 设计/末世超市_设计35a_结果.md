**请你在手机上量（3 局尸潮，第 10 关左右、丧尸 50 只以上的时候看）：**
1. 改前：小窗里把 5 个开关全关 → 退出重进 → 打 1 局，记最低帧数和毫秒。
2. 改后：5 个开关全开（默认）→ 退出重进 → 打 2 局，记同样的数。
3. 把数字发我，我写进这份文档。

### econ.mjs 算的结果（机器忙到几成、原料够不够）
按「每种商品顾客每分钟要多少」算，机器按这一级能升到的最高级：

**超市 2 级**：口碑 50 木工台 34%，口碑 100 木工台 76%；温室要 0.8 / 1.7 格（有 6 格）✓；木柴要 0.8 / 1.8 个/分，一个拾荒员工约 7 个 ✓。

**超市 3 级**（口碑 50 → 100）：
| 机器 | 忙 |
|---|---|
| 木工台 2 级 | 28% → 62% |
| 腌菜缸 3 级 | 26% → 57% |
| 分解机 3 级 | 13% → 30% |
| 蛋品机 / 果酱锅 / 熏炉 | 9% → 19% |

温室要 2.4 / 4.8 格（有 10）✓；果园要 0.5 / 1.2 棵（有 2）✓；鱼 1.3 / 3.0 条/分（一个钓鱼员工 3.7）✓；鸡蛋、鸭蛋 ✓；纯净水、绷带、木柴、电池（拾荒 + 回收机）✓。

**超市 4 级**（口碑 50 → 100）：
| 机器 | 忙 |
|---|---|
| 纺织机 | 26% → 60% |
| 腌菜缸 / 烘干机 | 20% → 45% |
| 果酱锅 / 罐头机 | 13% → 30% |
| 分解机 | 10% → 22% |
| 厨房 | 8% → 18% |
| 蛋品机 / 熏炉 | 7% → 15% |
| 木工台 ×2 | 6% → 14% |

温室要 4.4 / 8.0 格（有 14）✓；果园要 1.0 / 2.2 棵（有 4）✓；鱼 3.1 条/分（3.7）✓；兔毛、羊毛 ✓；纯净水最多 3.1/分（约 11）✓。

**超市 5 级**（口碑 50 → 100）：
| 机器 | 忙 |
|---|---|
| 纺织机 | 26% → 59% |
| 腌菜缸 / 熏炉 / 罐头机 / 烘干机 | 20% → 44% |
| 厨房 | 16% → 35% |
| 果酱锅 / 奶品机 | 13% → 29% |
| 分解机 | 10% → 22% |
| 蛋品机 | 7% → 15% |
| 木工台 ×2 | 6% → 14% |

温室要 5.2 / 9.7 格（有 16）✓；果园要 1.2 / 2.3 棵（有 4）✓；鱼 3.1（3.7）✓；牛奶、猪肉 ✓。另外加上牧场饲料（满级约 2.9 格温室 + 0.3 棵树），5 级口碑 100 一共要约 12.6 格，还在 16 格以内。

**为了够用改了什么（只改产量 / 用时，没动售价）**：第一次算时 3 级口碑 100 木工台忙到 **193%**（木工台用的是工坊通用的时间，配方又乘了 1.5）。改成木工台自己的时间 1～3 级 25 / 24 / 22 秒，去掉配方的 1.5 倍 → 2 级 76%、3 级 62%，都在 100% 以内。其他全部 ✓，没再改。
**要你知道的**：第 2 台木工台在 4～5 级只忙 6～14%（第 1 台就够了）。要不要让第 2 台有用一点（例如把木工台的东西卖得多一点、或者第 2 台晚点开），你定。

### 旧存档怎么换（存档版本 2 → 3，读档时自动）
- 货架上摆着已经不卖的货（布、苹果派）：退回仓库，再换成接替它的新货（布 → 毛衣、苹果派 → 炸茄条），数量不变。
- 货架上摆着现在变成原料的东西（鸡蛋、牛奶、木柴……）：退回仓库（原料不能上货架）。
- 神秘订单里要原料的：换成对应的加工品（木柴 → 木炭、鸡蛋 → 蛋黄酱、鸭蛋 → 咸鸭蛋、兔毛 → 帽子、羊毛 → 毛衣、牛奶 → 奶酪、猪肉 → 肉松）。
- 工坊里正在做、或者「工匠只做这个」选的东西现在没有了（布、苹果派）：那条线 / 那个选择清掉。
- 改名的机器（蛋品机、奶品机、熏炉）用的还是原来的存档字段，等级、在做的东西都不变。
- 超市 2 级以上的存档，进游戏弹一句提示：「木柴改成原料了：去「建造」→「工坊」盖木工台，把木柴做成木炭、手电筒、火炬再卖；牧场的蛋、毛、牛奶、猪肉也要在工坊做成东西卖」。
- 以前那次「松茸折成末日币」只对版本 3 以前的存档做一次，不会重复。
