# 18r 套装整套第一版结果（10-18，按 18q + 18l「预览不能转」）

截图：美术/检查截图/最新/（1017_1849_套装整套），info.txt 有每条怎么做的和改了哪些文件。

## 做了什么
- **套装整套直接用**：衣服1.glb（测试套，白 T 恤 + 浅灰长裤 + 米色鞋）整个当身体用，不切开、不换色、不删皮肤；只去掉头和露出来的脖子皮肤，接上第六版的脖子。套装 1.5 万面 + 发型头 1.5 万面，GLB 4.4 MB（原来 6.6 MB）。
- **皮肤区**：露出来的手臂、手、脖子用顶点颜色标出，游戏里换成脸的肤色（脚踝以下不算，米色鞋不会被当成皮肤）。
- **发色**照旧在游戏里换。
- **多套**：配置里 outfits 列几套，工具就做几套，都放进同一个 GLB（Outfit_<id>），游戏按选中的显示。套装多了以后再改成每套单独文件、按需加载。
- **发型头往下放多少**按最低领口自动算（露 1.5 厘米）；这套领口本来贴着下巴，所以不往下放。
- **创建人物**：男主角两页 发型（款式 + 发色 + 发尾）｜ 套装（一排缩略图，游戏里现拍），没有颜色排；预览固定正面往右 20°、平视、空手、站着呼吸，拖不动。
- **角色面板**的人物也固定角度、空手、不转；创建人物时手上的枪 / 鱼竿藏起来，回游戏放回。
- 检查截图：11 = 所有套装并排，16 = 发型 × 当前套装。

## 改了哪些文件
- tools/people3/hero.py：改成套装整套模式（设计 18q）：配置 outfits 可以列好几套，每套整个直接用，只去头、接脖子、做皮肤区遮罩；不再切上衣 / 裤子 / 鞋、不补内壁、不删身体；按最低领口自动算发型头要不要往下放；基础身体只用来量尺寸。旧的切开做法留在 hero_split_old.py。
- tools/people3/shots.mjs、compose.py：11 改成所有套装并排，加 16_发型x套装；info.txt 写每套的倍数、皮肤区比例。
- src/js/hero2.js：套装网格（Outfit_<id>）用身体材质（只换皮肤区颜色），按选中的套装显示；去掉衣服换色；加 OUTFITS 列表、套装缩略图（outfitThumbs）、近景固定角度 CLOSEUP_YAW。
- src/js/creator.js：男主角两页：发型、套装（缩略图一排、没有颜色排）；去掉拖动旋转；随机会挑套装。
- src/js/main.js：创建人物用单独的固定相机（正面往右 20°、平视、不被墙挡）；创建人物时手上的枪 / 鱼竿藏起来，回到游戏放回；角色面板人物不转、不拿枪。
- src/js/look.js、chars.js：外观里去掉鞋颜色、加 outfit；换外观时只传发色和套装。
- src/style.css：套装缩略图的样式；去掉拖动提示。
- src/js/changelog.js、help.js：加这次的说明。

## 以后上新套装
1. 用户出图（带颜色）→ 混元 → 存 美术/模型/套装_<款式>_<颜色>.glb。
2. 配置 outfits 加一行 {id, name, glb}，跑 `bash tools/people3/run.sh 配置.json "加套装 xxx"`。
