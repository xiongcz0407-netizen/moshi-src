## 一、每条线两种选法（logic.js wsAuto / wsWait / wsTick）

- **自动**（默认）：照旧挑最缺的，「货柜 + 仓库 + 线上在做的」最少的那样；这样做不了就换下一样。
  - 两个厨房在做的都算进库存。
  - 两个厨房自动挑菜时，别的厨房线上已经在做的菜先不挑，有别的能做就做别的。只有熟食柜上的菜比线少时才会重复。
- **指定一样**：只做这一样。没原料、到停手线、排队轮不到都**等着，不做别的**。
  - 设计60 的「选了的做不了就先做别的」已经删掉。
- **等着时显示**
  - 线上：「等原料：猪肉」「等原料：番茄（要留给货柜、动物）」「够多了（仓库 402 / 停手线 400）」「仓库放不下了」。
  - 机器头顶（几条线都停着时）：「停着：等原料」「停着：够多了」。
  - 原料一到、或者仓库降到停手线以下，下一次就开工。
- **抢同一样原料**（61a 的规则）：原料不到 60 个时，先给「货柜 + 仓库 + 线上在做的」少 30 个以上的那样。
  - 指定的线也排这个队，轮不到时写「等原料：猪肉（先给更缺的腊肉）」。
  - **不会一直轮不到**：所有空着的线按「等原料等了多久」排序，等得最久的先拿原料。同一条线等原料满 90 秒，就不再让给别人，下一个原料一定是它的。
  - 等「够多了」不算等原料。
- **工坊面板**
  - 每条线的按钮：自动写「选：自动 ▾」，指定写「指定：腊肉 ▾」。下拉照旧是「自动 / 各个产品」。
  - 右边详情里「线1 / 线2 / … / 全部线」也保留。
- **旧存档**：`lines[i].plan` 有值的就是指定，行为改成等着；没值的是自动。
- **说明文字**：工坊面板、「?」、游戏说明工坊那段都改成「自动：做最缺的；指定：只做这一样，没原料就等着」。
