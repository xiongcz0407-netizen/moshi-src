# 29a 通用面板框架 + 角色 / 仓库（V2.11，等确认后再改员工、建造、商城）

## 框架（src/js/ui.js 的 frame()）
- 标题栏：面板名 + 资源条（只放相关的几样）+ 「?」（原来底部的大段说明挪进这里）+ 关闭。
- 分页（多于 1 个才显示）→ 分页下面一条固定小条（可选）→ 格子区（固定大小，cols × rows，一页放不下左右翻页 ◀ ● ○ ▶，不上下滚）+ 右边详情区（点格子显示全部信息和按钮；没选时一句话）。
- 分页、页码、选中的格子按面板记住，点按钮重画后位置不变。
- 游戏只做横屏：去掉创建人物页、角色面板的竖屏排法；竖着拿手机照原来提示「请把手机横过来」。

## 角色（设计 28）
- 左边 3D 展示用人物 + 等级上限；中间 3 × 2 格（主角、伤害、射速、射程、手雷、🔒以后开放）；每格图标、名字、Lv、当前 → 下一级、带花费的升级按钮（钱不够的那项红字、按钮变灰；满级显示「已满级」；到上限显示「超市升到 X 级」）。
- 点格子：右边显示全部数值（手雷 3 项）、外观变化、缺什么、大的升级按钮。升级后那一格闪一下。
- 截图里一张就有四种状态：主角（钱够）、伤害（钱不够，💰400 红）、射速（满级）、射程（到上限）。

## 仓库
- 分页：货物 / 种子 / 珍品 / 钓鱼用品（没有的不显示）；顶上一条「仓库 X 级，每种最多 N 个」+ 整理。
- 格子 5 × 3：图标 + 数量（满了红字）+ 名字，紧缺角标；详情：仓库 / 货架上 / 售价、丢掉（−10 −1 +1 +10 全部）；珍品详情里「卖 1 个」。
