# 设计97a：副本里不显示超市飘字、屠夫关南墙不挡人 —— 结果（V8.61 → V8.71）

版本：**V8.71**（APP_V 871）。存档格式没变。分支 `d97`，已合并进 `main`。
截图：`美术/检查截图/1024_设计97/`

## 1. 副本里不再冒超市的飘字和提示
- **原因**：设计 84 只在 `main.js` 的 `handleEvents` 里把飘字（floatText）换成空的，但回收机暴击 ×10 走的是**横幅**（`UI.big`「暴击 ×10 / +10 罐头」），还会晃一下镜头，这两样都没拦。别处来的提示（`UI.toast`，比如仓库满、员工）也没拦。
- **改法**：在飘字入口统一拦（`src/js/ui.js`）：
  - `floatText`（飘字）、`big`（大横幅）、`toast`（提示条）三个入口都先看「是不是在副本里」（`main.js` 里 `UI.setMute(() => FBV.active())`），在副本里就不显示，回超市也不补放。
  - **副本自己的**飘字、提示（伤害数字、打断、技能名、背包满等）走 `UI.raw`。`main.js` 传给副本的 UI 就是 raw 版，所以不受影响。
  - **玩家自己点的**照常提示：副本里「获得」框的穿上 / 收下 / 分解、确认框，这些点完以后 0.4 秒内的提示不拦。打副本时按攻击、技能、摇杆不算「点」，不会把超市提示放出来。
  - 副本「读不出来」那两条提示改成直接走 raw（读取时已经算在副本里了）。
  - 回收机暴击晃镜头：副本里也不晃了。
- **测试**（毒囊关打 BOSS 时）：
  - 直接叫超市的「暴击 ×10」横幅、「×10 罐头」飘字、「仓库满了」提示，再让超市跑 10 分钟（生产、卖货、员工全走一遍）：横幅空的、提示条 0 条、超市飘字 0 个。
  - 同时按住攻击打 3 秒：副本自己的伤害数字照常飘（截图 `97_副本里超市暴击_打BOSS`）。
- **用到的文件**：飘字入口在 `src/js/ui.js`（文档写「你查」），另外 `main.js` 设开关、传 raw 给副本。

## 2. 屠夫关最南边不再被南墙挡住
- **改法**：主角被挡时，挡住的东西变半透明（`src/js/fb.js`，新加 `seeThrough`）：
  - 南边两段矮墙、四扇铁门、两边崖脚的石头，登记成「会挡人的东西」；
  - 每帧从镜头往主角的脚、腰、头连三条线，碰到谁的包围盒，谁就在 0.2 秒里变成 0.3 透明度，离开了再变回不透明；
  - 不透明时照常画（不进透明那一批，不会排序出错）。
- **结果**：
  - 主角在右下角（844、667）：右边那段矮墙变透明，整个人看得到；
  - 主角在最南边偏左：左边铁门、矮墙变透明；
  - 主角走开以后都变回不透明（截图 `97_屠夫关最南边左边`）。
- 毒囊关南边是毒雾墙，没改。
