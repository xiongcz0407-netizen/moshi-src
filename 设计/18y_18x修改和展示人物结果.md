# 18y 按 18x 检查意见 + 18l 最新版改完的结果（V1.81）

## 18x
1. **女生头跟男生一样大**：每颗发型头按「头顶到下巴的高度 = 男发型1」以下巴为中心放大 / 缩小（工具里自动做，以后新发型头都会校）。女发型1 算出来是 **× 1.42**，不是 × 1.1：男发型1 头发往上翘得高，女发型1 头顶是平的；截图里量，以前女头高只有身高的 21%（男 30%）。现在男女头一样高，女生的脸看起来比男生略大一点。如果觉得太大，可以改成按别的量法（比如只比脸），你定。
2. **统一肤色**：全员用男发型1 的脸颊色（#d8b399）。女发型1 的脸贴图只校皮肤色的像素，眼睛、腮红、头发不动；套装皮肤区都用这个色。
3. **粉开衫红斑**：前胸两块 + 背后下摆，换成开衫的粉色（配置里粉套装 `red_fix: true`）。
4. **男女分开、定死**：配置里每颗发型头、每套套装都有 `sex`。创建人物页选男只列男发型1 / 学院风蓝，选女只列女发型1 / 学院风粉；切换男女换成该性别默认搭配，发色保留；读旧存档 / 随机时对不上就换默认（测过：女 + 男发型 + 蓝套装的旧存档读档后变成女发型1 + 粉套装，发色不变）。截图 16 男女各一张，只放同性别组合。
5. 蓝套装用现在的，不重做。

## 18l 最新版（角色界面）
- 创建人物、改外观、角色面板、头像都用**单独的展示用人物**：只有发型头、发色、套装、骨骼、待机动作，不挂枪 / 鱼竿 / 背包；游戏里的主角在创建人物时先藏起来，确定后原样出来（不再「藏枪再放回去」）。
- **站姿**：原因是待机动作把手臂往下转 36°（按旧身体写死的，旧身体手臂是平的），新身体 A 字站姿手臂本来就往下 20°，再转 36° 就插进身体 / 袖子。现在按身体自己的手臂角度算：只往下 10°，手垂在两侧、离身体留空隙。男女都试过。
- 角度固定正面往右 20°，不能转。
