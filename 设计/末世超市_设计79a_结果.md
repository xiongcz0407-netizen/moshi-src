# 设计79a：屠夫本空气墙、翻滚方向、打完不能动、确认框 —— 结果（V6.21）

版本：V6.11 → **V6.21**（APP_V 621）。存档格式没变。
截图：`美术/检查截图/1022_设计79/`

## 1. 空气墙（木箱）
- **原因**：木箱掩体写的是 `prop('crate')`，模型表里没有这个名字（真名是 `p:crate`）。读不到就什么都没画，但掩体的碰撞照样在，所以是一堵挡子弹、挡人的空气墙。
- **改法**
  - 改成 `prop('p:crate')`。
  - 4 个掩体都走新的 `coverProp()`：模型读不到时，在副本错误记录（性能小窗红字、`__g.FB_ERR`）写「掩体模型没读到：名字（用方块代替）」，再放一个同样大小的方块（箱子是木色方块，油桶是圆柱）。以后不会再有看不见的墙。
- **在哪个包**：`p:crate` 和油桶 `barrel` 都在 HOME_PIRATE 里，属于基础包，进游戏前就下好了。
- **4 个掩体**（场地 x −6.6～6.6，z −13～19）：砧板 (0, 0.5)、推车 (−4.3, 6.5)、木箱 (4.4, −3.2)、油桶 (−4.4, −6.6)。俯视图里 4 个都有模型，`FB_ERR` 是空的。

## 2. 翻滚方向
- **摇杆只认自己的手指**
  - 原来按攻击键（第二根手指）时，摇杆的 lostpointercapture 会把摇杆清零，翻滚就变成往后滚。
  - 现在摇杆、攻击键、技能键各记自己的 pointerId，别的手指的抬起、取消都不管。lostpointercapture 不再清摇杆。
  - 手指滑出摇杆区也跟着走（document 上按 id 过滤）。
- **翻滚方向按顺序取**
  1. 这一帧的摇杆方向；
  2. 摇杆没推的话，用 0.3 秒内最后一次推的方向；
  3. 都没有，才往面朝的反方向滚。
- **?debug**：左下角一行「摇杆 x, y　翻滚 ax, az（摇杆 / 0.3秒内 / 面朝反方向）」。

## 3. 打完不能动
- **原因**
  - 打赢后 `step()` 直接 return，人不能动，走不到宝箱，「打开宝箱」出不来。
  - 「回超市」要开了宝箱才出现。
  - 撤退键里有 `if (fight.over) return`，打完以后点了没反应。
  - 三样加起来，打赢后就完全卡住了。
- **改法**
  - 打赢后能走、能转身，不能开枪、放技能，也不受伤。打输照旧不动。
  - 打完点「撤退」直接回超市，不弹确认框。宝箱没开的话，回到门前弹「获得」框。
  - 打赢时把攻击键的按住状态和 pointer capture 都放掉（`releaseKeys()`），离开副本时也放一次。
  - 撤退键和结束按钮（打开宝箱 / 回超市 / 再打一次）放在最上层，不会被技能键挡住。
  - 每帧都包了 try/catch：出错写进性能小窗和 `FB_ERR`（同一条只记一次），不会整个卡死，按钮照样能回家。

## 4. 确认框
- 5 个浏览器自带的 `confirm()` 都换成游戏里的确认框（UI.ask），危险的按钮是红色：

| 地方 | 文字 | 按钮 |
|---|---|---|
| 副本撤退 | 撤退算输，尸潮卷不退。确定撤退吗？ | 撤退（红） |
| 尸潮撤退 | 撤退算输，没有奖励。确定撤退吗？ | 撤退（红） |
| 卖塔 | 卖掉这座塔？退回一半的钱。 | 卖掉 |
| 设置·重新开始 | 确定重新开始？现在的进度会清空。 | 清空重来（红） |
| 设置·清掉手机资源 | 清掉手机里存的模型、图片，刷新后重新下载（存档不受影响）？ | 清掉（红） |

- 确认框开着时，副本、尸潮都暂停：测过框开着 1.5 秒，战斗时间一点没走。
- 确认框在 HUD 上面。
- lint 加了规则，代码里再写 `confirm` / `alert` / `prompt` 会报错。

## 测试（无头 Chrome，触屏模拟，CDP 多点触摸；844 × 390 和 667 × 375 各一遍）
| 测试 | 结果 |
|---|---|
| 翻滚 4 个方向（一根手指推摇杆，一根手指点翻滚） | 左 (−1, 0)、右 (1, 0)、上 (0, −1)、下 (0, 1)，都是「摇杆」 |
| 按住攻击，再往右推摇杆，第三根手指点翻滚 | (1, 0)，「摇杆」 |
| 松开摇杆马上点翻滚 | 用 0.3 秒内的方向（「0.3秒内」）；松开 0.8 秒后点：往面朝的反方向 |
| 按住攻击打死屠夫再松手 | 打赢；之后「打开宝箱」「回超市」都点得动 |
| 打赢 → 走到宝箱 → 打开 → 获得框 → 收下 → 回超市 | 走到宝箱旁出「打开宝箱」；获得框有 穿上 / 收下 / 分解；收下后出「再打一次 / 回超市」；回超市后 HUD 正常 |
| 打赢后直接点「撤退」 | 不弹框，回超市，门前弹「获得」框 |
| 打着点「撤退」 | 弹新确认框，战斗暂停；确定后算输，run = 0 |
| 尸潮里点「撤退」 | 弹新确认框；确定后尸潮结束 |
| 性能小窗 / FB_ERR | 没有错误 |

- 在无头 Chrome 里一帧比较慢，「松开马上翻滚」时离最后一次推摇杆正好 0.3 秒，浮点数多了一点点被算成超时。所以比较时加了 0.000001 的余量。手机上一帧 1/60 秒，不会碰到。
- 测试路线：木箱在屠夫倒下的地方和宝箱之间，直线走会被木箱挡住（这是对的），测试脚本绕过去走。
- lint 0 错误；fbtest 41 项、t70 13 项、t72 8 项通过；core2、tdg 通过。
