## 1. 厨房 2 用厨房的图标
- ui.js 加了 `BD_ICON = { kitchen2: 'kitchen' }`，按 BUILD 的 key 找建筑图标都走 `icon('bd', k)` 这一个函数，改一处全生效。全局查过，现在用到建筑图标的只有两处：
  - 建造面板（格子和详情）；
  - 牧场列表（棚的图标）。
- 工坊面板标签、头顶牌子只写字，不用图标。
- main.js 预读图标的清单里去掉了 `bd_kitchen2.png`（这张图不存在，以前会白请求一次）。

## 2. 松茸蒸蛋只放熟食柜（还是蛋品机做）
- `GOODS.mushegg` 加了 `only: 'deli'`，跟冰淇淋只放冰柜是同一套写法：
  - 普通货架选货里没有它；
  - 熟食柜选货里有；
  - 「有 N 样货没上架」也只会把它领到熟食柜。
- 价格（110）、顾客挑中的机会（w 0.4）不变。
- 熟食柜说明改成「只放熟食（厨房的菜、松茸蒸蛋）」，建造面板、游戏说明两处都改了。说明的「商品解锁」里也写了松茸蒸蛋放熟食柜。
- 8 道菜 + 松茸蒸蛋 = 9 种，要 3 个高档熟食柜（一个放 4 种）。熟食柜照设计39 不限数量。
- **旧存档**：普通货架上摆着的松茸蒸蛋，读档时退回仓库，那一格变空（沿用读档时「放错柜子的退回仓库」那条）。t70 加了一项检查：摆 7 个，仓库 0 → 7，那格空了。

## 3. supplysim（超市 5 级，60 分钟 × 3 局）
- 熟食柜改成不限数量：能盖熟食柜，就按要摆几种来配。这次配了 3 个，9 种都摆上。
- 普通货架的总数原来也受「这一级最多几个货柜」限制：熟食柜多占一个，南瓜子、苹果干就没地方摆。所以这次加了 `FULL=1`，货柜不限数量（设计39）。

- 松茸蒸蛋、鸭蛋、松茸都够。牛奶、猪肉、兔毛、羊毛是 0 的时间都 ≤ 3%。
- **要留意的**：口碑 100 自动时胡萝卜过量率 0.88（< 1.3）。
  - 熟食柜从 2 个变 3 个，南瓜汤、鱼汤摆得更全，厨房做得多了；
  - 胡萝卜仓库 60 分钟里净少了 15 个左右，但最低还有 145 个，货柜没空过；
  - 设计70 那次（2 个熟食柜）是 1.72。
  - 要是你在游戏里看到胡萝卜不够，再加胡萝卜的种子或产量。
- 全部指定时肉松 < 1.3，跟设计70 一样（被肉松饭吃掉）。
