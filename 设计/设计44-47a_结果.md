## 二、同一种货能摆多个货柜（设计45）
- **选货**：
  - 别处在卖的不再变灰、不锁，格子下面写「也在 2、5号卖」；
  - 一个货柜的几层也能放同一样（setShelf 去掉了「同一个货柜不放重复的」）。
- **没上架**：「能卖（有人要）、仓库有、哪个货柜都没摆、店里有能放它的货柜」的货：
  - 选货格子右上角写红色「没上架」；
  - 货架页顶上一个红色按钮「有 N 样货没上架」，点了跳到第一个能放它的货柜，优先有空层的，左边选中它，右边切到那一层；
  - 货柜种类页签上也有红点；
  - 菜单货架红点 = 有空货柜没选货，或者有货没上架。
- **补货**：同一种货在几个货柜 / 几层上时，按「装了几个 ÷ 容量」最低的先补，一个一个轮着补。
- **顾客**：
  - 按离东门的远近（店里网格步数）排货柜，先去最近的、还有这样货的拿；
  - 拿空了再去下一个，画面上也会走过去（新加了 c.more，记要去的第二、三个货柜）。
- **扣口碑**：本来就是看所有货柜加起来是不是 0，不用改。
- **厨房**：本来就是「哪个熟食柜摆着都算」，没改。
- **头顶牌子**：
  - 这样货所有货柜都空了，才写「×× 缺货」；
  - 只是这个货柜空了、别的还有，画一个灰色小点；
  - 就近升级的 ⬆ 照样画在牌子右上角。
- 游戏说明「开店卖货」、货架「?」都改了；「顾客想买的没货扣口碑」改成「所有货柜都没了才扣」。

### supplysim：最贵的 3 样各多摆 2 个货柜（推荐配置，每级 10 局，口碑 100，用的是最后的代码）
| | 3 级（熏鱼、火炬、手电筒） | 5 级（肉松饭、鱼汤、南瓜汤） |
|---|---|---|
| 过量率（不多摆 → 多摆） | 熏鱼 1.50 → 1.75，火炬 1.82 → 1.84，手电筒 1.90 → 1.91 | 肉松饭 1.77 → 1.76，鱼汤 1.72 → 1.76，南瓜汤 1.81 → 1.82 |
| 有没有 < 1.3 | 没有 | 没有 |
| 货柜是 0 的时间 | 都是 0% | 南瓜汤 0.1%，其余 0% |
| 仓库最低 / 仓库是 0 的时间 | 熏鱼 92 / 0%，火炬 0 / 18%，手电筒 0 / 18% | 肉松饭 0 / 1.7%，鱼汤 2 / 0%，南瓜汤 0 / 5.5% |

- **仓库会不会一下子被拿空**：会。多摆的 2 个货柜一下要装几十个，仓库这样货会被搬到货柜上，然后工匠的停手线是「仓库 + 货柜」，所以仓库常在 0 附近。
- 不过货柜上一直有货，顾客买得到，过量率也没掉到 1.3 以下。
- 要注意：员工每天吃的罐头、水，神秘商人要的货，都只从仓库拿。如果把罐头、水摆很多货柜，仓库可能不够员工吃。现在员工吃饭会先从仓库、不够从货柜拿，所以影响不大。

## 六、修 bug：布置后施工围栏不跟着走
- 原因跟你说的一样：updSite() 的 key 里只有 S.layout（货柜），没有 S.fix.ws（工坊机器）。现在 key 里加上了机器的摆法，挪了就重新算位置。
- 货柜升档：key 里本来就有 S.layout，所以没问题。动物棚、塔位不能挪，也没问题。
- 跟着机器走的其他东西逐个查过，都是从 S.fix.ws 或 W.wsItems 算的，挪了自动跟着走：
  - 头顶名字牌、制造进度；
  - 暴击飘字；
  - 工匠站的位置；
  - 就近升级按钮和头顶 ⬆；
  - 碰撞。
  - 货柜也一样，都是从 S.layout 算的。
- 测试：
  - 奶品机升级中，挪到工坊左下角：围栏和施工牌在新位置，碰撞框也在新位置。
  - 同时有一条线在做：进度 20 秒 → 挪完 24 秒，接着走，没丢。
  - 货柜升档中挪位置：没单独实测，靠的是本来就有的 S.layout 那一段。

## 九、员工效率用到工匠和饲养员（设计47）
- 一人管几台 / 几个棚：普通、精英 3，史诗 4，传说 5（config 里 STAFF.qual.manage）。
  - 好几个人时，按效率从高到低，先管 WS_IDS / 鸡鸭兔羊牛猪前面的。
- 速度倍数 = 1 + 0.5 ×（效率 − 1）：
  - 工匠管的机器每条线做得快；
  - 饲养员管的棚周期变短。吃的东西照旧按时间算，所以同样的菜能多产。
- 界面：
  - 员工详情「效率 ×2.62 → ×2.72」，下面一行「用处」。例如「管 4 台机器，做得快 81%」；种地「干活快 162%」；收银「结账快 162%」；拾荒、钓鱼「每趟多带 162%」。
  - 升级按钮上面一行「升级后 效率 2.62 → 2.72」。
  - 工坊页签旁边那条写「工匠：阿宝 Lv10（快 81%）」，剩余秒数按快了以后算。
  - 牧场棚牌子写「饲养员：秀兰（快 9%）」，下一批的时间也按快了以后算。
  - 建造面板「工匠不够 / 饲养员不够」改成按实际管得过来几台算。
- 游戏说明（工坊、员工两节）、员工「?」都改了。
- **资源优先顺序（货柜 > 喂动物 > 工坊）**：以前工匠只给能卖的原料留 5 个。现在多留两样：
  - 「货柜上摆它的那几层补满还差多少」；
  - 「吃它的动物吃两顿」。
  - 多出来的才拿去做。

### supplysim（每级 10 局，口碑 100）
| 员工 | 超市 | 工匠 / 饲养 | < 1.3 的 | 货柜是 0 最多的 | 菜果仓库最低 |
|---|---|---|---|---|---|
| 精英 1 级（原来） | 3 级 | 2 / 1 | 没有 | 都是 0% | 萝卜 23、苹果 7、茄子 2 |
| 精英 1 级（原来） | 5 级 | 4 / 2 | 没有 | 玉米饼 2.2% | 南瓜 0、松茸 0、萝卜 4 |
| 史诗 10 级 | 3 级 | 2 / 1 | 没有 | 苹果 1.1% | 苹果 0、萝卜 6 |
| 史诗 10 级 | 5 级 | 3 / 2 | 萝卜 0.95、玉米 1.00、南瓜 0.87、苹果 1.14 | 都 ≤ 0.1% | 萝卜 0、玉米 0、苹果 0、橙子 0 |
| 传说 20 级 | 3 级 | 2 / 1 | 没有 | 苹果 1.4% | 萝卜 0、苹果 0 |
| 传说 20 级 | 5 级 | 3 / 2 | 萝卜 1.00、番茄 1.24、玉米 0.99、南瓜 0.99、苹果 1.04、橙子 0.97 | 苹果 1.9%、橙子 0.7% | 菜果大多到 0 |

- **结论**：
  - 工坊没有抢货柜的菜：货柜上菜果是 0 的时间最多 1.9%，跟原来差不多。
  - 但 5 级员工练高了以后，机器、厨房快了很多（传说快 185%），把种出来的菜果多余的部分都用掉了。所以菜果的过量率掉到 1.0 左右：种多少用多少，仓库里攒不起来。
  - 原料（蛋、毛、奶、肉）反而多得多，例如兔毛、羊毛结束时 600～700 个。
- **要不要改，等你定**：
  - A 菜果卖得多的时候，工坊少做（停手线跟着菜果库存）；
  - B 5 级多一块温室 / 种地员工效率也翻倍；
  - C 不改（货柜不缺，只是攒不下来）。
- 我试过把预留加大到「货柜那几层从空补满一次」，5 级反而有肉松饭 18% 没货（猪肉被留住了），所以退回现在这个。
- **推荐配置（12 台机器、6 个棚）**：

  | 员工品质 | 工匠 | 饲养员 |
  |---|---|---|
  | 普通 / 精英 | 4 | 2 |
  | 史诗 | 3 | 2 |
  | 传说 | 3（12 ÷ 5 进 1） | 2 |

  - 3 级（6 台机器、2 个棚）：都是工匠 2、饲养员 1。
