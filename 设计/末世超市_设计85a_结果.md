## 1. 星星兑换，667 宽：「兑换」被截掉
- 667 宽（屏宽 ≤ 720）时压紧了下面几处：
  - 说明写成一行，例如「5 颗 → 25000 末日币」；
  - 加减那一排的按钮矮一点；
  - 标题和小字的空隙小一点。
- 实测 667 宽：「兑换」按钮底边在 335，详情框底边在 345，整个露出来，不用往下拉。
- 844 宽：说明还是原来那句「花 5 颗星星 → 得到 5 × 5000 = 25000 末日币」，样子没变。

## 2. 星星兑换格子名字

- 右边详情的标题照写全称和数量（「5000 末日币」）。

## 3. 主角页签升级按钮里的表情

- 全游戏扫了一遍按钮，剩下的表情就这一处。另外一处 ✓ 是文字符号（生产线选中的勾），不是表情，没换。

## 4. 炼宝成功金光外圈发灰
- **原因**：原图是白底上的金光，外圈是一层发白、不怎么黄的淡色。「越白越透明」抠完以后，这层还带着一点透明度，叠加到暗底上就是一圈灰雾。
- **改法**（tools/cut_refine.py，只重切 ref_burst）：
  - 从半径 0.45 开始越往外越透明，到 0.9 全透明；
  - 外圈发白、不黄的地方颜色换成金黄，叠加时不会是一层灰；
  - 中间亮芯、光芒照留。
- 4 个品质用的是同一张金光，外面那圈品质色光没动。普通、史诗、套装、传说四种都截了修前修后对照：`85_炼宝金光_四个品质_修前修后`。外圈干净地淡出，没有灰边了。

### 6.1 左上角套装角标
- 所有套装图标（eqIcon q-s、副本掉落列表的小图标）左上角有一颗绿色星星，白描边加一圈深色细边，一半在框外、一半在框里，像贴上去的徽章。不用黄色，跟右下角的「N★」分得开。
- 大小：72 大图标 20px，44 普通图标 15px，28 小图标 11px，24 掉落列表图标 10px。比文档写的略大一点，原来那个尺寸在手机上看太小；都不盖住装备主体。
- 用到 eqIcon 的地方都有，包括：背包 / 装备列表、角色装备栏、炼宝页、炼宝动画里、结算拿到装备的框，以及副本掉落列表。

### 6.2 + 6.3 边框流光，星越高越华丽（看这件自己的星）
全是 CSS 动画：一圈只露出边框宽度的遮罩，里面一块锥形渐变在转。只转 transform，不跑 JS，列表里多件也不卡。

| 星级 | 效果 |
|---|---|
| 0～3★ | 一道流光，3.2 秒一圈，偏暗 |
| 4～7★ | 流光变亮，2.2 秒一圈；图标里加很淡的绿色内发光 |
| 8～11★ | 两道流光反向转；框外偶尔飘出两颗绿色小光点 |
| 12★ | 流光变绿金色；图标后面一圈慢慢转的符文光环（特效图左上格，去掉中间白光，压暗，露出框外一点）；右下「12★」变成金色、加亮 |

- 72 / 44 图标四档都有。28 / 24 小图标不跑整圈，只有淡淡的呼吸闪光。
- 只有套装加，普通、史诗、传说不变。
- 截图：
  - `85_套装图标_0_4_8_12星并排`：同一件 0 / 4 / 8 / 12★，大、中、小三种尺寸；
  - `85_套装流光_连续第1/2/3帧`：间隔 0.3 秒，流光在动。

### 6.4 角色页人物光效（新文件 heroaura.js）
- 「主角」页签、装备页左边的人物都有，只在角色页开着时跑。
- 看同一套穿了几件（5 件，护符不算）和这几件里最低的星。两套都没凑齐时按件数多的那套算。换装、升星以后马上刷新。
