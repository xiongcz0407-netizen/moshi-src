# 设计39 + 设计41 + 待改小问题（V3.21）

## 一、设计39：货柜写名字、货柜不限数量

### 1. 名字
- **货架面板的货柜卡片**：每个图标下面写名字，12px，可以换行、不截断；空的格子写「空」。卡片放不下就自动加高。
- **其他只有图标的地方**：
  - 仓库：每格本来就写了名字。
  - 神秘商人订单：本来就写了名字。
  - 就近升级小窗：花费写了「末日币」「工具箱」。
  - 工坊配方里的原料小图标、各处花费的小图标：写不下名字，**点一下或按住出名字**，1.6 秒后消失。只对小图标（34px 以下）生效，大格子里本来就写了名字。
- 货架面板顶上改成「货柜 N 个」。原来写的「新货柜在『建造』里买」放不下了，跟「布置货柜位置」按钮叠在一起，所以去掉了。

### 2. 货柜不限数量
- **去掉了两个上限**：每种的个数上限（表的长度），和每级超市的总数上限 fixtureMax。现在只看店里有没有空位（spotFor）。
- **没空位时**写「店里放不下了，先在『布置』里挪一挪，或者升级超市（店面变大）」。
- **超出价格表的**：
  - 价格 = 上一个 × 1.3（取整到 100）；
  - 工具箱 +1（最多 5 个）；
  - 用时、要的超市等级跟最后一档一样。
  - 例子：
    - 货架第 10 个 15600、第 11 个 20300；
    - 果蔬架第 3 个 2000 + 工具箱 2；
    - 冰柜第 3 个 5200 + 工具箱 3；
    - 熟食柜第 3 个 6500 + 工具箱 3。
- **建造格子**写「已有 N 个」；详情写「已有 N 个，买第 N+1 个」。
- **超市升级说明**：原来写「货柜最多 N 个」，改成「店面更大、能多放货柜」。
- **货柜头顶的牌子**：原来最多准备 14 个，改成 40 个。超市 5 级的店里实际最多能摆 35 个。

## 二、设计41：产量要过量（规则：推荐配置下每样货产量 ≥ 卖掉的 1.3 倍）

### supplysim 新加的输出
- 每样货输出：「卖掉/分」「仓库 + 货架净增/分」「过量率」。< 1.3 的标 ✗。
- 过量率 =（卖掉 + 净增 + 满了丢掉）/ 卖掉。
  - 多算了一项「满了丢掉」：仓库或池塘满了，员工带回来的东西就丢了，但这些也是产出来的。例如 4 级的鱼，池塘只养得下 60 条，鱼多半是这样丢的。
- 以下两种情况写「满」，算产量够（东西多到放不下，或者工匠因为够多了主动不做）：
  - 这样货在仓库里满着的时间超过 10%；
  - 工坊做的东西到了停手线（仓库 + 货架 ≥ 停手线的 90%）的时间超过 10%。
- 1～5 级都跑，4、5 级另外跑口碑 50。每种情况 10 局（4 级口碑 100 跑了 20 局），每局先跑 30 分钟不记，再记 60 分钟。
- 摆满货柜（FULL=1，店里能放多少放多少）也跑了 3、5 级：**没有 ✗**。
  - 原因：推荐配置里每样能卖的货本来就都有地方摆了。顾客来得多快只看口碑和超市等级，跟货柜个数没关系；多出来的货柜没有新东西卖，所以过量率不变。

### 改了哪些数字（售价没改）
**工匠停手线**
- WS.enough 改成 max(30, 仓库每种上限 × 40%)。仓库 1～5 级是 30 / 48 / 100 / 200 / 400。
- 木工台原来写死「木炭不到 40 个才做」，改成跟停手线走。
- WS.keep、资源优先顺序（货柜 > 喂动物 > 工坊）没动。

**机器用时**（乘在原来的用时上）

| 机器 | 倍数 |
|---|---|
| 纺织机、甜品机 | × 0.7 |
| 木工台、腌菜缸 | × 0.6（先 × 0.7，3 级时木炭、腌菜还不够） |
| 烘干机 | × 0.85（4 级爆米花、南瓜子、苹果干不到 1.3） |

**种的东西**

| 东西 | 改了什么 |
|---|---|
| 苹果树 | 每次 34 → 50（先 +30% 到 44，3 级还是不够） |
| 橘子树 | 每次 32 → 48 |
| 萝卜 | 种子比重 26 → 36 |
| 番茄 | 种子比重 15 → 24；120 → 90 秒 |
| 卷心菜 | 种子比重 28 → 33；每格 3 → 4 个 |
| 茄子 | 180 → 120 秒；每格 5 → 6 个 |
| 胡萝卜 | 180 → 120 秒；每格 5 → 6 个；种子比重 15 → 17 |
| 玉米 | 240 → 200 秒 |
| 南瓜 | 240 → 200 秒；种子比重 14 → 13 |
| 松茸 | 360 → 300 秒 |

- 萝卜、番茄选的是改种子比重。只改种子比重不够：温室的地是固定的，加了萝卜、番茄的种子，别的菜就少了。所以慢的菜也缩短了时间，卷心菜、茄子、胡萝卜每格多收 1 个。

**其他**

| 东西 | 改了什么 |
|---|---|
| 钓鱼员工每趟带回 | 11～16 → 28～42 条 |
| 池塘能养几条 | 1～3 级 20 / 40 / 80 / 150 → 30 / 60 / 120 / 200 |
| 拾荒员工带回的瓶子 | 5～9 → 6～11 |
| 拾荒员工带回的铁罐 | 5～9 → 6～10 |

- 回收机加快是因为超市 1 级时回收机最高 2 级，处理不过来。

**员工收菜、补种（顺手改的）**
- 以前仓库里某种菜满了，熟了的地就一直占着收不了，别的菜也种不下去。3 级跑久了，「熟了没收」能到 44%。
- 现在：
  - 员工收菜、摘果子时，仓库放不下也收，放不下的丢掉（会提示）；
  - 员工补种时，仓库已经到 80% 的菜先不种（都快满了才照旧）。
- 主角自己点收菜还是原来的样子：放不下就不收。

### 仓库满了的提示
- 仓库面板里满了的那格右上角写红色的「满」。
- 员工带回来的东西放不下丢掉了，消息里提示「仓库 ×× 满了，员工带回来的放不下就丢了，升级仓库」，每 10 分钟最多一次。会触发的情况：
  - 拾荒带回的东西这种满了；
  - 钓鱼带回的鱼池塘放不下；
  - 收菜、摘果子放不下。
