## 技能（`fbcore.js` 的 `TYRANT_CFG` / `tyStep`）
| 招式 | 做成什么样 |
|---|---|
| 机炮点射 | 安静时间每 1.6 秒一轮：主角脚下小圆（半径 1、0.6 秒）一连 3 个（半血 5 个），间隔 0.3 秒、跟着主角出；BOSS 到圈心中间有掩体就打在掩体上 |
| 旋转激光 | 身前一条长红线（16 米）1.2 秒，核心变亮 → 激光 2 秒扫 180°（方向随机）；半血两束对着转。翻滚无敌能穿，16 米外扫不到，掩体挡不住，扫过的地方留烧痕 |
| 导弹齐射 | 导弹箱开，主角周围依次 5 个圆（半径 1.6，第 1 个在脚下），间隔 0.35 秒，每个 1 秒落地；落点留火 3 秒。能打断（没发的不发） |
| 激光网格 | 全场 4 横 + 3 竖细线（宽 0.8），1.4 秒后横线打，**0.6 秒后**竖线打；半血 5 横 4 竖。主角附近一定有一条线；**格子至少 2.5 米**（fbtest 抽 11 次，最小 2.53） |
| 地毯轰炸 | 全场每 2 米一个圆，留 3～4 块空地（半血少 1 块），第 1 块空地离主角 2.5～5 米；1.6 秒落第一波，**0.8 秒后**第二波；第二波每块空地离第一波某块空地 ≤ 5 米（fbtest 最远 4.76）。落点 15% 留火 2 秒 |
| 能量护盾 | 单膝跪地，蓝光罩，升 3 根柱子（血 = BOSS 的 2%）；柱子之间电弧（碰到每秒 0.3）；护盾时 BOSS 受伤 −80%，跪着每 2 秒一轮机炮；**柱子算小怪，普攻优先打**。3 根都掉了破盾：瘫 2 秒、受伤 +30% |
| 电磁牵引 + 贴脸霰弹炮 | 「电磁牵引」1 秒，脚下蓝圈；然后 1.2 秒把主角往 BOSS 吸（每秒 9 米，走路约 5 米，往外走会被拖进去，翻滚能挣出去）→ 身前扇形（半径 5、90°）0.5 秒后轰一炮（击退 3 米）→ 马上接导弹齐射。牵引能打断（不接霰弹炮） |
| 电磁脉冲 | 「电磁脉冲（全场）」1.5 秒，警报变蓝；全场扣 110（必吃）→ **技能封锁 3 秒**：集火、翻滚、震荡弹按不了（按钮灰 + 电火花，左上「封锁 2.6」，按了头顶写「封锁中」）；封锁完 3 秒内不再封锁；接地毯轰炸 |
| 过载主炮（大招） | 红色施法条 3 秒，地上一条红线跟着主角慢慢转（每秒 0.42 弧度，比绕着跑慢）；开炮整条直线大伤害，**掩体挡**（被打的掩体变黑），地面熔化 4 秒（每秒 0.2） |
| 半血破甲 | 身上一震，3 块装甲板飞出去落地当掩体；受伤 +15%，走得快 30%，机炮 5 个圈，护盾 4 根柱子，激光双束，网格 5 横 4 竖，地毯空地少 1 块 |
| 灭杀 | 106 那套；护盾、激光、牵引都停。打下来时核心自爆：白光 + 一圈圈冲击波；期间不掉血（fbtest 验过） |

- 出招顺序照文档：激光网格 → 导弹齐射 → 旋转激光 → 电磁牵引（+ 霰弹炮 + 导弹）→ 地毯轰炸 → 能量护盾 → 电磁脉冲（+ 地毯轰炸）→ 激光网格 → 过载主炮（循环）。每 5 秒一招（半血 4.5），第一招开场 3 秒后，安静 1.2 秒。
- 站位：离主角超过 9 米才慢慢走过来；不追近身。

### 跟文档不一样 / 要设计定的
1. **护盾加了 25 秒上限**（文档没写）。机器人有时打不到最远那根柱子，护盾一直不破，3 分钟就完了；真人也可能卡住。25 秒到了 BOSS 自己站起来，**不算破盾**（不瘫、不 +30%）。要不要这个上限请设计定。
2. **牵引速度 9 米 / 秒**（文档没给数）：6 米 / 秒时，主角读条那 1 秒先往外跑，就根本吸不到。现在读条时站着打，吸起来再往外走，会被吸到 1.8 米（霰弹炮打得到）；往外翻滚能挣到 5.4 米（打不到）。
3. **数值还没调到目标（见下面 fbsim），要设计看**。

## fbsim（`STAGE=5`，血量 120000 / 普通技能 620 / 大招 800，100 局）
- 新装备线：`GEARSET=atk6` / `def6`（史诗 6 星 + 拾荒者头盔、护甲 6 星 + 护符，Lv4）；上一关的线 `atk5`。
- 机器人：
  - 旋转激光马上扫到就翻滚（走位好提前 0.25 秒、一般 0.12 秒），不然往外跑；
  - 牵引时一直往外走，走位好被吸到 3.5 米内往外翻滚；
  - 护盾时走到最近的柱子 6.5 米内（被掩体挡着就绕过去），躲圈也往柱子那边躲；
  - 封锁时翻滚不了。

| 装备 | 走位好 | 走位一般 | 目标 |
|---|---|---|---|
| 全攻击（atk6） | **80%**，中位 140.3 秒，必吃伤害最多 8% | **85%** | ≥ 90% ✗；25～50% ✗ |
| 偏防御（def6） | **86%**，中位 125.4 秒 | **87%** | ≥ 95% ✗；≥ 70% ✓ |
| 上一关装备（atk5） | **43%** | — | < 30% ✗ |
| tank（站着不躲） | none / 拾荒者 4 件 6★ / xiongL 都是 0/30 | — | ✓ |

| 每局 | 被封锁 | 被吸到身前 | 被霰弹炮打中 | 吃激光网格 | 吃地毯轰炸 | 吃旋转激光 | 打掉柱子 |
|---|---|---|---|---|---|---|---|
| 全攻击走位好 | 1.22 | 1.57 | 0.00 | 0.00 | 0.68 | 1.32 | 平均 12.0 秒 |
| 全攻击走位一般 | 1.47 | 1.63 | 0.11 | 0.02 | 0.93 | 1.08 | 平均 12.2 秒 |

**为什么调不到**：
- 这一关机器人「走位好」和「走位一般」几乎一样（一般有时还更好）。伤害大头是机炮小圈（每局 5～7 下）和护盾电弧、火（4～6 下），这两样跟反应快慢关系不大：机炮圈跟着人打，掉头时总会吃到。
- 网格、地毯、霰弹炮两种机器人都躲得开。
- 所以加伤害两边一起掉，减伤害两边一起涨。「全攻击走位一般 25～50%」和「全攻击走位好 ≥ 90%」拉不开。
- 上一关装备（atk5）跟 atk6 输出差得不多，主要差在血（1107 / 1516），所以也很难压到 30% 以下。
- 试过的组合（40 局，全攻击好 / 一般、偏防御好 / 一般、atk5）：
  - 165000 / 560：护盾卡住，全输；
  - 135000 / 850：33 / 57、60 / 73、8；
  - 125000 / 650：63 / 68、88 / 93、23；
  - 120000 / 560：75 / 83、93 / 93、45；
  - **120000 / 620**（现在用的）：75 / 90、93 / 93、35。
- **请设计定**：
  - 要不要在必吃伤害（电磁脉冲）上加码，或者让封锁时的地毯轰炸更难，拉开走位好 / 一般；
  - 机炮小圈要不要改成「预判」（打主角前面）或者减少；
  - 或者接受现在的数，等 116B 素材到了、第 6 项合并时再调。
