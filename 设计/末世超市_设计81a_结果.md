## 0. 副本改成「每关一份配置」
- **fbcore.js**
  - 新加 `STAGES[n]`：场地（ARENA）、掩体（COVERS）、BOSS 身体半径（bossR）、子弹打 BOSS 的高度（hitY）。
  - `setStage(n)` 换成这一关的；`createFight(n)` 开头就换。
  - BOSS 的招式按关分：第 1 关照旧走屠夫那一套，第 2 关走 `toxStep`。毒囊的数都在 `TOX_CFG`，动作时间在 `TOX_ANIM`。
  - 通用部分照旧共用：主角、按键、开枪、翻滚、技能、震荡弹打断、狂暴、预警判定、回血。
    - 震荡弹打断改成通用：招式有自己的 `cancel` 就调用它。毒弹就是这样，打断以后还没出的毒弹不出了。
    - 毒池的减速走 `st.moveK`。
- **fb.js**
  - 每关一个场景，建好留着，进哪关切哪个。
  - 模型按关读：`models/fb/…` 是第 1 关，`models/fb2/…` 是毒囊；崖边石块、宝箱共用第 1 关的。
  - 第 2 关的场地、毒囊、特效都在新文件 **fbtox.js**。fb.js 每帧调它的 `onEvent`、`bossFrame`、`frame`、`pusFrame`。
  - 通用部分没动：战斗界面、施法条、预警着色器、粒子、子弹、宝箱、获得框、撤退、读取（设计74）。
  - 镜头按关：毒囊关视角 46°（屠夫关 34°），更远、更平、往北多看，看得到毒囊整个上半身和头；退出副本时还原。
- **开放**
  - `BOSSES[2]`：血 84,000、普通技能 205、大招 340，`open: true`，6 条技能说明。
  - 规则照旧：先打赢第 1 关才能打第 2 关。
- **屠夫关没坏**
  - 改完以后，设计79 的整套屠夫测试都过了：4 个方向翻滚、打赢走到宝箱开箱、获得框、回超市。
  - fbsim 屠夫用时跟改前一样，中位 123.2 秒。
  - fbtest 第 2 关的检查改成「先打赢前一关」，第 3 关「还没开放」，42 项全过。

## 2. 毒囊的骨骼和动作
- **骨骼**：17 根骨，用 Blender 装（脚本在 `fb2/rig/`）。
  - 脊柱、胸、脖子、头、**下巴**（单独一节，嘴能张开），还有肚子。
  - 两条手臂：肩、上臂、前臂、手、手指。
  - 权重先在体素代理上自动算，再转到原模型；下巴、肚子手工补。
  - 减面 50,000 → 22,000。
- **11 个动作**，都是关键帧加程序抖动；「预警填满那一刻 = 喷出 / 拍到 / 炸开」，游戏里按预警时长调动作速度：

| 动作 | 时长 | 出手时刻 | 内容 |
|---|---|---|---|
| 待机 | 3.0 秒循环 | | 一起一伏喘气、肚子一胀一缩、嘴一张一合，两只手的手指错开着动 |
| 酸液喷吐 | 1.5 | 0.8 | 往后仰 → 往前伸脖子张大嘴 |
| 毒弹·鼓气 | 0.6 | | 鼓肚子、头往后仰 |
| 毒弹·吐一发 | 0.45 | 0.12 | 头往前点一下、张嘴（每发播一次） |
| 毒囊爆裂 | 2.1 | 1.15 | 全身鼓起来发抖、头缩进肩膀 → 头猛地一抬、张嘴 |
| 拍地（左手 / 右手） | 2.6 | 1.5 | 手抬高 → 重重拍下 → 停一下 → 收回扒着崖边 |
| 毒雾上涌 | 2.8 | 2.0 | 两手离开崖边张开、仰头长吼、头左右甩 |
| 受击 | 0.4 | | 往后缩 |
| 狂暴 | 2.0 | | 仰头吼一声、抖 |
| 倒下 | 3.0 | | 嚎叫 → 手松开、往后滑。往下沉进毒雾在代码里做 |

- 身上的脓包跟着身体动。
- 脓包发光是在着色器里按贴图的黄绿色自动挑出来，一明一暗；毒囊爆裂时全身一起亮。

## 2b. 头
- **技能空档跟着主角转**
  - 只转脖子和头：左右最多 70°（脖子 40%、头 60%），上下 25°；转不过来时胸口多转最多 15°。
  - 有重量：用弹簧慢慢跟上，停下时稍微过头再回来。跟待机的呼吸动作叠在一起。
- **放技能时不看主角**
  - 一开始放技能就交给技能自己的动作：毒弹时头转向每一发的落点，拍地时盯着要拍的那块，毒雾上涌、毒囊爆裂、狂暴、倒下时不看。
  - 放完以后 0.3 秒慢慢转回来看主角。
  - 测：主角在左边 (−5.5, −5) 头转 −25°，右边 +24°，南边 0°。
- **头上一直有的特效**
  - 眼睛：黄绿色柔光球 + 亮芯，一明一暗。
  - 嘴角：每 0.3～0.6 秒滴一滴绿液，一路掉进崖下毒雾。
  - 嘴里每 2～4 秒冒一小缕毒气。
  - 头、肩上的脓包也亮。
- **放技能时头上的特效**

| 技能 | 头上的特效 |
|---|---|
| 酸液喷吐 | 嘴前喷出光带 + 飞溅 |
| 毒弹 | 喉咙越来越亮；每吐一发嘴边一团小绿雾 |
| 毒囊爆裂 | 眼睛变亮黄、快速闪；全身脓包一起亮 |
| 拍地 | 拍下那一刻眼睛亮一下 |
| 毒雾上涌 | 眼睛变红；嘴里往上喷毒雾和毒雾丝；头顶出「毒雾上涌」 |
| 狂暴 | 之后眼睛一直红，光更大；身上淡淡一层红 |
| 倒下 | 眼睛的光慢慢灭 |
| 被打断 | 眼睛暗一下（0.6 秒），头晃一下（受击动作） |

## 3. 场地
- **台地**：宽 14、长 38（x −7～7，z −16～22），台地岩石贴图。随机撒 11 块小毒水滩、被腐蚀的地面（装饰，不伤人）。
- **崖**
  - 左、右、北三面断崖（南边也是崖，桥接进来）。崖壁代码做，往下 11 米、越往下越往外。
  - 崖边摆山崖石块，只露个头。远处两边、北边也是高崖壁。
- **崖下毒雾海**：在台地下 8.5 米和 6.6 米两层，反向慢慢流。
  - 崖边一路往上冒毒雾丝（同时最多 14 缕），零星飘大团毒雾（最多 7 团，都很淡）。
  - 主角走到崖边就是边界，掉不下去。
- **南边**：破铁桥接到对岸。主角开场站在台地南端 (0, 19)，桥在身后。桥是装饰，走不上去。
- **掩体 4 个**，两边错开：
  - 裂石 (−3.9, −7.5)
  - 毒桶堆 (3.8, −3.2)
  - 断管道 (−3.4, 2.8)，横着
  - 枯树桩 (3.6, 8.2)
- **毒囊**
  - 在北边崖下 (0, −17.6)，放大 12 倍，露出上半身约 6.6 米。
  - 两只手扒在台地北边缘，手下面有被腐蚀的地面和焦坑贴花。
  - 腰下面接一截身子沉进毒雾（模型底下是平切的），腰上一圈毒雾慢慢转。
  - 身体是能打的目标（半径 3.6 米），两只手不挡子弹。

## 5. 招式
| 招式 | 实现 |
|---|---|
| 普攻·酸液喷吐 | 主角离毒囊的嘴 12 米内、技能空档才用，每 3～4 秒一次。小扇形（半径 13、张角 31°）预警 0.8 秒，伤害 × 0.6，留一块酸液喷溅 3 秒 |
| ① 毒弹 | 3 个圈（半径 1.6），间隔 0.5 秒，每个落在主角当时的位置。每个预警 1.2 秒，落地前 0.6 秒从嘴里吐出、划弧线飞过去。伤害 × 1，落点变毒池 |
| ② 毒池 | 冒泡的大毒池 + 气泡，留 8 秒（半血以后 10 秒），最后 1 秒闪；最多 8 个，多了最早的先消失。站在里面每 0.5 秒扣「普通技能 × 0.25 × 0.5」（每秒 × 0.25），减速 30% |
| ③ 毒囊爆裂 | 鼓 1.15 秒（能打断）→ 4～5 个脓包飞出去，落在主角周围 2.5～7.5 米、互相隔 3 米。每个圈半径 2.5，3 秒填满就炸（伤害 × 1.2，留焦坑 4 秒）。脓包血量 = BOSS 的 1.5%，普攻优先打（跟小怪一样），打掉就不炸。脓包一明一暗，越快炸闪得越快 |
| ④ 拍地 | 左右轮流。台地北段宽 6、长 7 的长方形，伤害 × 1.3 + 往南打退。尘土、碎石、裂纹 4 秒、镜头震。毒囊的左手（画面右边）拍右边 |
| ⑤ 毒雾上涌（大招） | 主角在哪边就涌哪边，半边场地整条亮红，预警 2 秒，施法条红色，打断不了（只慢 50%）。涌上来时在里面扣大招 340，之后 4 秒内每 0.5 秒扣「大招 × 0.15 × 0.5」。画面：那半边盖一层流动的毒雾 + 崖边翻上来的毒雾墙 + 大团毒雾 |
| ⑥ 半血以后 | 毒弹 5 个、毒池 10 秒。每 25 秒两边往里收 0.6 米，最多 2 次（场地两边各窄 1.2 米）。收之前 3 秒两边亮红线、提示「两边的毒雾要往里收了！」；收了以后那一条盖一层毒雾 |

- **出招顺序**：毒弹 → 毒囊爆裂 → 拍地 → 毒弹 → 毒雾上涌 → 拍地。第一招开场 4 秒后，间隔 7 秒，普攻插在中间。
- **狂暴后**：间隔 5.5 秒，顺序换成毒弹 → 毒雾上涌 → 拍地 → 毒囊爆裂 → 毒雾上涌 → 拍地（毒雾上涌更勤）。
- **震荡弹**：能打断毒弹（没出的不出）、毒囊爆裂、拍地、酸液喷吐；毒雾上涌只慢 50%。
- 这一关不叫小丧尸。
