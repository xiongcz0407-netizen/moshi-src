# 18u 去掉男主角旧的衣服换色（10-18，按 18q）

## 做了什么
1. 男主角外观只剩**发色**和**套装**两项：look.js 的默认值、随机都不再有上衣 / 裤子颜色（这两项只留给女主角的旧模型）；chars.js 的 setLook 遇到新男主角直接跳过 lookTexture（不换贴图、不染衣服）；main.js 生成主角（角色面板）不再传衣服颜色。
2. makeHero2：先读模型里带的套装信息（套装 id、肤色、内壁色）再改 userData。另外把遮罩从「顶点颜色」改名成 aMask，材质不再开顶点颜色——以前如果哪段代码把顶点颜色当颜色乘上去，皮肤区（R = 1）就是红的，现在这条路彻底没有了。
3. 旧存档：读档、改外观时用 cleanLook 清理，男主角去掉旧的 shirt / pants / skin / hair / shoes。
4. 左上角头像、创建人物页角落的小头像：男主角改用新模型拍的固定角度头像（正面往右 20°）。女主角还是 2D 头像。
5. 真游戏里检查（截图在 检查截图/最新/17_真游戏_*）：创建人物（发型页、套装页）、游戏里近看、角色面板、左上角头像、旧存档读进来，都没有红色。

## 改了哪些文件
- src/js/look.js：男主角的外观只剩发色（hc / hc2）和套装（outfit），默认值、随机都不再有上衣 / 裤子颜色；新增 cleanLook：读档时男主角去掉旧的 shirt / pants / skin / hair / shoes，女主角缺的补默认。上衣 / 裤子颜色选项只留给女主角（旧模型）。
- src/js/chars.js：setLook：新男主角直接 return，不再生成 lookTexture、不替换贴图、不染衣服（这段只给女主角用）。
- src/js/hero2.js：makeHero2 先读模型里带的套装信息（套装 id、肤色、内壁色）再改 userData；遮罩从顶点颜色改名成 aMask，材质不再开 vertexColors（任何情况下都不会把遮罩当颜色乘上去变成全身红）；新增 heroPortrait：新模型拍固定角度头像。
- src/js/main.js：角色面板人物不再传衣服颜色；左上角头像、创建人物角落头像男主角用新模型拍的头像；读档、改外观时用 cleanLook 清理旧数据；菜单里「改外观」的说明改成发型发色、套装。
- src/js/creator.js：头像改用 main.js 传进来的新头像；换男女、随机按性别给对应的选项。
- src/js/changelog.js：V1.61 加一条。

- 女主角还是旧模型，上衣默认红色是旧模型本来的样子，没改。
