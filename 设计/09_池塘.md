# 09 池塘（0.22）

用户 10-13 用询问框定的：

| 项 | 定的 |
|---|---|
| 位置 | 原来医院那块地（院子南边，POND_LOT -24, 16.4） |
| 怎么有 | 「建造」里盖，超市 3 级（和钓鱼一起开放）；占施工队 |
| 等级 | 1 级 40 条（超市 3 级，1500 币 + 1 工具箱，30 分钟）→ 2 级 80 条（超市 4 级，4000 币 + 2 工具箱，1 小时）→ 3 级 150 条（超市 5 级，9000 币 + 3 工具箱，2 小时）；池塘跟着变大 |
| 放鱼 | 坐船回来、员工钓鱼回来，鱼自动放进池塘，弹一句「X 条鱼放进池塘了」；放不下的留在背包里，走到池塘边自动放 |
| 没盖池塘时 | 鱼先放在池塘地上的几个水桶里，最多 20 条，冰柜照样能补；盖好后自动倒进池塘。老存档仓库里的鱼也先进水桶（放不下的照样保留） |
| 卖鱼 | 冰柜选「鱼」就自动从池塘捞鱼上架（池塘就是鱼的仓库）；仓库面板不再显示鱼 |
| 繁殖 | 不繁殖，只存鱼、看鱼游 |
| 池塘界面 | 走到池塘边出现「看池塘」按钮；面板列出每种鱼：图标、名字、稀有度、几条、单价；顶上写池塘 X/40 条 |
| 画面 | Kenney 鱼模型按每种鱼的颜色和大小，最多同时游 30 条（多了只显示 30 条），慢慢游、偶尔转弯；稀有、传说的鱼身上有微光 |
