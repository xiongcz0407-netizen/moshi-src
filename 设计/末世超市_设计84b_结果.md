# 设计84b：毒雾上涌地面绿色边缘虚化 —— 结果（V7.01 → V7.11）

版本：**V7.11**（APP_V 711）。存档格式没变。
截图：`美术/检查截图/1022_设计84/84b_上涌_3铺满半边_边缘虚化_844.png`（跟 84_上涌_3 同一个镜头，都是上涌后 0.65 秒）

## 原来的问题
压在地上的那层绿色有两处是硬的，看起来像一个框：
- 雾的内边只有 1 米左右在过渡，判定线以内浓度是一整片一样的，过渡的地方看出来是一条直线；
- 判定线上还画了一条直的淡红线。

## 改了什么（fbfog.js 贴地雾的着色器）
1. **判定线以内**：照样浓，保持 0.22～0.35，只随贴图和噪声有一点点起伏。玩家看得出哪边危险。
2. **判定线外侧**：
   - 绿色先往外伸 0～1.4 米，伸多远由两层噪声决定，所以边是弯弯曲曲、一块一块的；
   - 伸出去以后再用 0.45～1 米淡掉，一共 1.5～2 米左右；
   - 淡出带里的浓淡也一块深一块浅。
3. **边会动**：噪声随时间慢慢漂移（每秒 0.05～0.18），边一直在蠕动。
4. **中间那条直的红线去掉了**，收边的红线也一起去掉了。
   - 收之前 3 秒的崖边红色预警线还在，没动。
5. **靠判定线那几团雾**可以稍微越过线一点，这样雾团那一侧的边也不是直的。
6. **收边那招**同样处理：判定线（场地边）以内浓，线以内侧 1.2 米左右弯弯曲曲地淡出。
7. **伤害判定没改**：上涌还是整半边，收边还是那 0.6 / 1.2 米。

## 测试
- lint 0 错误。
- 虚拟时间截图，没有报错。
- 单看地面那层（把雾团藏起来）：边已经是弯曲的，看不出直线。
