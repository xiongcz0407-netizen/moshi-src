# 18e 男主角第一版（10-17，照设计 18c / 18d 做的）和发型的问题

## 做了什么（tools/people2，输出 models/people/hero_m2.glb + face_atlas.png/json）
- **身体**（基础身体.glb）：5 万面 → 6000；自己建 21 根骨头（名字跟 Kenney 一样），自动权重；站 / 走 / 跑 3 个动作（Q 版腿短，步子快一点）。贴图的透明通道记「哪里是皮肤」，游戏里皮肤换颜色、背心短裤不变；衣服盖住的身体和鞋里的脚不画。
- **脸型**：圆脸（原样）、方脸、长脸、瓜子脸，形态键只改下半张脸，身体和脸上的五官薄片一起变。
- **五官**：yanjing.jpg、meimao-zui.jpg 切成 33 小块（去掉格子线和字，白底抠掉，眼白保留）；脸前面贴一层薄片，用一张 512 画布画五官。瞳孔灰色部分 × 瞳色；眉毛跟发色（暗一点）。眨眼 3～5 秒一次；表情：卖出 / 收获 / 建好 → 笑眯眼 + 大笑 1 秒，挨打 → 闭眼 + 皱眉 + O 嘴 0.5 秒，打尸潮 → 锐利眼 + 挑眉。
- **衣服**（衣服1.glb 拆成 T 恤、长裤、短袜、帆布鞋）：去掉里层、贴合身体、传骨骼权重；鞋绑在左右脚骨头上，穿鞋把脚藏起来；裤腰藏在 T 恤里；每件能换颜色，鞋底不染。
- **发型**：发型男1.glb 去掉假人头，挂在头骨上。头皮被头发盖住的地方涂成发色。
- **创建人物**（只男的有）：脸型、眼睛 + 瞳色、眉毛、嘴、小装饰（单独一框，可多选，创可贴 / 脏印子能换左右脸）、肤色、发色 + 发尾渐变、T 恤 / 长裤 / 帆布鞋颜色。女的还是原来的。
- 一个人约 2.5 万三角面（身体 6000、脸 2500、头发 6000、T 恤 4100、裤子 2500、袜子 500、鞋 3000），只有主角一个人，手机能扛；以后 NPC 要另做简化版。

## 发型为什么变丑（用户 10-17：「这么好看的发型为什么被你截出来这么丑」）
对比了原模型和游戏里的：确实是两样东西。原因按影响大小：
1. **假人头和我们的头形状差太多**：发型男1 是戴在**瘦长的鹅蛋形假人头**（长脖子、长脸）上生成的；我们的身体是 **Q 版大圆头**（宽比高还大）。要套上去只能**压扁**（高度缩到 0.62、宽度 0.8），长长的侧边头发、垂到脸颊的发片全被压短；刘海本来盖到假人的眉毛（假人脸长），套到大圆头上会盖住整个眼睛，只好**往上挤**，就成了一刀切的齐刘海。
2. **头发和假人头是同一个网格**（混元生成的是一整块），去假人头时，贴着头皮的那层头发也一起删了一部分。
3. 减面 5 万 → 6000，一缕缕缎带的细节少了。
4. 我给头发用了 3 档的卡通明暗，原模型那种缎子一样的过渡光泽被压平了。

## 以后发型怎么生成（给提示词窗口 / 用户）
**最关键：发型要「戴在我们自己的大圆头上」生成，不要戴在混元默认的假人头上。** 这样大小、比例、刘海的位置一开始就是对的，写代码的窗口只要等比例放上去、去掉头，不用压扁。
1. 用我们身体的光头渲染图当底图：美术/模型/光头参考_正面.png、光头参考_侧前.png（写代码的窗口已经出好）。
2. **Google 改图**（上传光头参考图），英文：
   Using this exact bald chibi character head as the base, keep the head shape, size, ears and the blank face completely unchanged, and add 【发型描述】 on it. Large smooth glossy satin-like hair ribbons, a bright halo highlight ring, slightly curled tips, short bangs that stop above the eyebrows so the eyes stay fully visible, light ash-blonde color, soft toon-shaded 3D render, front view, plain white background, no text
   - 发型男1 这一款重出就填：【a fluffy short anime hairstyle with airy bangs, a few strands lifted on top with two small ahoge, side locks reaching the cheeks, a short wolf-cut back covering the nape】
   - 4 个一张的合图模式也可以：同一个大圆头画 4 次，每个戴一种，2 × 2，互不碰到。
3. **混元图生 3D**，面数选最高；出来的头就是我们的头形，写代码的窗口按颜色 / 形状去掉头，**只等比例缩放**。
4. 刘海一定要在眉毛以上（「露出眼睛」）；侧边、后面可以长，套上去不会被压扁。

## 写代码的窗口这边也会改
- 只等比例缩放，不再压扁；刘海太长就剪短，不往上挤。
- 头发减面少减一点（主角一个人，头发 1 万面左右）。
- 头发的明暗改成平滑过渡 + 缎子光泽（高光带跟着视角走），不用 3 档卡通明暗。

## 第二版（10-17，按设计 18c「定下来的做法」）
- **标准头**（美术/模型/标准头.glb）替换身体的头：按头顶、后脑、两侧对齐身体原来的头，等比例缩放 0.489；身体原来的头删掉，脖子留着伸进标准头底下（标准头底部没脖子）。减到 1 万面，贴图 2048。
- 第一版的五官薄片、脸型变形、眨眼和表情、五官 / 瞳色 / 脸型 / 小装饰选项全部去掉；yanjing.jpg、meimao-zui.jpg 不再用。
- **肤色**：身体皮肤 = 标准头贴图的肤色（#c19a7f），固定，不能选。
- **男发型1**（美术/模型/男发型1.glb）：按跟标准头重合的部分 + 肉色删掉头，只等比例缩放（0.545），刘海不剪、盖着眼睛；减到 1 万面；光滑缎面（PBR 粗糙度 0.38 + 环境反射 + 边缘亮边），灰度 × 发根→发尾渐变，高光加在染色之后。头发底下的头皮（按头发量出来）涂成发色。**后脑没有露出来**。

- 创建人物（男）：发色（发尾可渐变）、T 恤 / 长裤 / 帆布鞋颜色。
- **身体参考_正面.png**（美术/模型/）：基础身体正面全身、A 字姿势、白底、光头、空白脸，给 18d 生成衣服用。
