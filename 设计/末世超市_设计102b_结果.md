# 设计102b 结果：第 3 关落石巨人检查后的修改（开发1，分支 d102b）

用时：开始 21:23、结束 21:41，实际用时约 18 分钟（按环境时钟，太平洋时间）。当时报的预估是 40～70 分钟。
版本：还是 **V9.01**（还没发布，所以不再 +10）。更新记录在 V9.01 下面加了一条。

## 1. 开场全景黑屏 ✓
- **原因**：贴图没读完就开场了。副本的贴图是「先给一张空贴图，图到了再换上」，空贴图画出来是黑的。干净浏览器第一次进第 3 关时，进到战斗那一刻场景里 81 张贴图有 34 张还没读到，地面、石壁、铁轨都是黑的。雾、天空颜色、开场镜头位置都没问题。
- **改法**：建好场地以后，等这一关用到的贴图（场景里的，加上特效图）全部读完才开场。没读完时一直停在读取界面（进度条），最多等 15 秒，读失败的那张不等。三关都这样。
- **测试**：干净浏览器（新的浏览器环境，没有缓存）第一次进第 3 关，进到战斗那一刻还没读到的贴图是 **0 张**。
  - 正常网速：读取界面约 13.8 秒后开场。
  - 限速（150ms 延迟、400KB/s）：读取界面约 21.5 秒后开场。
  - 两种情况第一帧都是完整场地。
- 新加一个测试脚本 `tools/test/s_rock_first.mjs`（用 `SLOW=1` 测慢网）。

## 2. 半血裂开时身体变形 ✓
- **原因**：裂开这个动作本身做得太狠，模型的权重没有问题，跟设计 84 不是一回事。以前的动作里，左手横过胸口去捂另一侧，身体再前倾将近 70°，石拳往上翻，权重被扯得整个人揉成一团。
- **改法**：动作重做，每个关节都只动一点。
  - 身子先往后一抽，头扭向石化那一侧，左手往外张，不过胸口中线。
  - 0.7 秒时石拳往下一坠，同时掉下那块石头，身子微微前倾，最多比平常站姿多前倾 10°。
  - 然后抖两下站稳。
  - 动作文件在 `tools/golem_rig/anim.py`，重新导出了 `golem.glb`。
- **截图**：裂开过程连续 4 帧（0.3 / 0.55 / 0.8 / 1.15 秒）。第 3 帧石头从石拳上掉下来，第 4 帧砸地，身体全程没有变形。
- 另附 Blender 里改前、改后的动作对比图。

## 3. 地裂改成一整条连着的裂缝 ✓
- **改法**：用代码画一条连续的裂缝带，不再一块块贴裂纹印子。
  - 主干从巨人脚下一直裂到分叉点，越往前越宽。
  - 两叉从主干末端接着裂出去，越往外越细，Y 字一眼就看得出来。
  - 边缘是锯齿状，中线左右有曲折，接头处不折，所以首尾连得上。
  - 一共三层：外圈把地面压暗、中间黑缝、缝里一条会呼吸的橘光。
  - 裂缝消失时一起淡出，用过的模型和材质会释放掉。
- 判定没有改，还是原来的线段 + 宽度。
- **截图**：地裂预警、地裂裂开以后。

## 4. 巨人追到跟前看不到脸 ✓
- **改法**：头看主角时，离主角 6 米以内脖子和头会往上抬，越近抬得越多，2.5 米以内抬到最大，胸口也跟着挺一点。离得远时跟以前一样。镜头没有改。
- **截图**：「巨人追到跟前」（主角 (0, 5)、巨人 (0, 1.6)）。整张脸露在 BOSS 框下面（头顶在 117px、下巴在 138px），看得清正脸。
