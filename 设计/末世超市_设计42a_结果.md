# 设计42：仓库超过上限（木柴 1020/1000）（V3.31）

## 是哪里漏了
往仓库加东西的地方逐个查过：

| 地方 | 以前 | 现在 |
|---|---|---|
| **回收机**（木柴、罐头、水、绷带、电池都是它出的） | 只在开始回收前看「这种满没满」，出 ×3、×10 时直接加 3 个、10 个，不看还剩多少空位。木柴 1020/1000 就是这里来的：仓库 999 时出了一个 ×10，再加上 ×3。 | 走新的 putStock：放得下多少加多少，放不下的丢掉并提示 |
| **货柜换货、退回仓库** | 直接加 | putStock |
| **顾客没买成、退回仓库**（尸潮开始、出门时没人收银关门） | 直接加 | putStock |
| 鱼（顾客退货、货柜换货时退回池塘） | 直接加 | 也看池塘上限，放不下的丢掉 |
| 工坊出产、分解机顺带出的铜丝 | 已经用 whRoom 限制 | 没问题 |
| 收菜、摘果子 | 41a 已经改成放不下就丢 | 没问题 |
| 员工钓鱼、主角背包里的鱼放进池塘 | 已经限制 | 没问题 |
| 牧场动物产出 | 已经限制，放不下的留在棚里等 | 没问题 |
| 拾荒 | 带回来的先进物资堆，再进回收机 | 由回收机那条管 |
| 商人 | 卖的都是发条、饵料、施工队这类，不进仓库 | 没问题 |
| GM 改存档 | 在服务器上直接改数字 | 读档时会压回上限（见下） |

- 「放不下的丢掉」跟 41a 一样：消息里提示「仓库 ×× 满了，员工带回来的放不下就丢了，升级仓库」，每 10 分钟最多一次。
- 旧存档：读档（migrate）时，每种货超过仓库上限的压回上限；鱼超过池塘上限的，每种鱼按比例减掉。不丧的存档读进来以后，木柴是 1000/1000，没有一样超过。

## 跑 supplysim 发现的
- 修完以后，超市 1 级的绷带、罐头、水过量率掉到 1.08～1.2。以前能 ≥ 1.3，是因为 ×10 超出上限的部分等于白送。
- 另外查到两个原因：
  - 拾荒员工一趟带回的东西先放铁罐、瓶子，物资堆 60 件满了以后，破布就进不去了，所以绷带少；
  - 回收机按排队顺序回收，不管哪种已经快满。
- 改了这几处（售价没改）：
  - 带回来的东西先打乱再进物资堆；物资堆 60 → 100 件；
  - 回收机先回收仓库里最少的那种；
  - 回收机 2～5 级每件 2.0 / 1.95 / 1.9 / 1.85 → 1.7 / 1.65 / 1.6 / 1.55 秒；
  - 超市 1 级破布 ×1.7 → ×2.2（跟铁罐、瓶子一样）。
- supplysim 的判断加了一条：满了丢掉的 ≥ 卖掉的 5% 也算够（写「满」）。东西已经多到仓库放不下，产量本来就过量。
- 重新跑了一遍（1～5 级各 10 局，4、5 级加口碑 50）：**全部 ≥ 1.3，没有 ✗**，跟 41a 一样。
