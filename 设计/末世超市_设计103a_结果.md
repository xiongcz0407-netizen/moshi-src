## 改了什么（只改 fbcore.js 出招节奏，伤害和预警时间都没动）
1. 大技能之间：`gap` 7 → **4.2** 秒（设计给的是 4.5，为什么改见下面「调过的数」），还是只在闲着时倒数；狂暴后 `gapRage` 3.5 秒。大技能之后安静 `calm` 2.5 → **1.8** 秒，狂暴 1.4 秒。
2. 普攻（投石、横扫）：
   - 冷却 `basicCd` 0.8 → **2.5** 秒。以前其实没有冷却：只在硬直结束时补一个 0.8 秒，所以投石一直刷。
   - 普攻后只安静 1 秒（`basicCalm`）。
   - 离下一个大技能不到 2.5 秒就不放普攻（`basicGuard`）。落石雨期间不受这条限制。
3. 出招顺序改成 10 招一轮 `grab → rift → roll → ava → pillars → grab → roll → rift → ava → pillars`，山崩每 5 招一次；第一招在开场 3 秒放。
4. 连招：
   - 地裂硬直完不安静，直接接下一招。顺序上下一招就是滚石或石柱阵时，按顺序接；下一招不是这两种（比如轮到山崩）时，滚石、石柱阵轮流接一个，山崩留着照常排。
   - 半血以后换成 8 招一轮：`grab → rift → roll → ava → pillars → roll → rift → ava`，山崩每 4 招一次，从地裂开始，所以不会连着两次抓掩体。
   - 半血以后石柱阵放完直接接一次**投石**。「接投掷」我理解成投石：抓掩体要先走过去，接不成连招。如果设计要的是抓掩体，再说。
   - 半血裂开动作结束后，照常安静 1.8 秒。不加的话会马上出招，最短空档只有 0.13 秒。

## 调过的数
- gap 4.5（设计给的）：投石 16 次（> 10）、大技能 18.6 次（< 20），不达标。原因是 4.5 − 1.8 = 2.7 秒，比 2.5 秒多一点，每两个大技能之间还会塞进一次投石。
- gap **4.2**：达标，用这个。
- gap 4.0：也达标（大技能 23.3、山崩 4.6、中位 157.7 秒），可以当备选。

## 要设计看：剩血 60～80% 只调 gap / calm 达不到
- 会躲的机器人剩血平均 99%，最低 81%。挨打伤害从 58 涨到 103，但机器人血 983，只掉 1 成。gap 降到 4.0，平均还是 98%。
- 原因：每个技能都有 1.5 秒预警（大招 2 秒读条），机器人躲得几乎全中，挨到的主要是落石雨和贴身横扫。光调出招密度，伤害上不去。
- 要到 60～80%，得动伤害或预警（这次没动，等设计定）。可以考虑这几个方向：
  - 落石雨波数 / 范围加大；
  - 连招之间压到预警时间更短；
  - 机器人躲得太完美，比真人强（可以把 fbsim 机器人的反应时间调慢，再看剩血）。
