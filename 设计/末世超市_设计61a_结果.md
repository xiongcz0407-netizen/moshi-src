## 1. 副本里 BOSS 常在画面外

- BOSS 出了画面，屏幕边上会有一个红色箭头指着他，箭头会一伸一缩。箭头靠上时会留出 BOSS 血条的位置。

## 2. 左上角「无敌 9998.6」

- 这是我截图时脚本给主角加的测试无敌（`inv = 9999`），游戏代码本身不会给这么久的无敌。
- 正式版里只有两种情况会出「无敌」：翻滚 0.4 秒、不灭之铠 2 秒。
- 现在左上角只显示 3 秒以内的无敌。截图和测试改用 `player.god`，这个字段画面上不显示，正式版代码里也没有地方会设它。

## 3. 尸潮「现在几关」对不上

- 原因：60a 截图时脚本把 `S.td.best` 改成了 4 来拍「✗」，可每关的「打赢过」看的是 `S.td.wins`，两个数就对不上了。
- 改法：新加 `tdCleared(S)`，就是 `S.td.wins` 里打赢过的最高一关。用它的地方：
  - 尸潮面板顶上
  - 建造面板「通关尸潮第 N 关 ✓/✗」
  - 超市升级条件
  - 任务提示
  - 「先打赢前一关」
  - 任务「尸潮打赢第 3 关」
- 读旧存档时会把 `best` 也改成这个数。

## 4. 不丧的存档猪肉一直 0（已修，supplysim 能复现）

**原因不是猪棚，也不是没喂。** 存档里的情况：

- 猪棚 3 级，住了 6 只（满了）。饲养员阿娟（史诗）在管，南瓜有 818 个，猪一直吃饱。
- 猪肉产量大约每分钟 9～10 个。

问题出在 4 样东西都抢猪肉：肉松、腊肉、午餐肉罐头、萝卜炖肉。原来每台机器只管自己做「最少的那样」，不看别的机器缺不缺。结果是：

- 萝卜炖肉已经有 372 个、午餐肉罐头 232 个，还在用猪肉。
- 腊肉只有 69 个。
- 猪肉一出来就被抢光，熏炉一直「原料不够」。牛奶也是一样的情况。

**修法**：同一样原料仓库里不到 60 个时，几台机器抢它，先给「货柜 + 仓库 + 线上在做的」最少的那样。别的产品比它多 30 个以上，就先让出来，线上写「猪肉先给更缺的腊肉」。

**supplysim 能复现了**：用 `REAL=存档路径` 直接跑真实存档，新加了一行「原料仓库是 0 的时间」。

| 不丧的存档跑 30 分钟 | 修之前 | 修之后 |
|---|---|---|
| 猪肉仓库是 0 的时间 | **35%** | 3% |
| 牛奶仓库是 0 的时间 | **38%** | 0% |
| 腊肉过量率（< 1.3 算不够） | **0.71** | 够了 |
| 结束时 腊肉 / 肉松 | 69 / 70 | 110 / 110 |

- 普通 supplysim（超市 1～5 级，各 2 局 × 60 分钟）：所有商品卖空的时间都是 0%，没有过量率低于 1.3 的。
- 超市 4、5 级还有一个「电芯仓库是 0 的时间约 65%」，修之前就是这样（关掉这次的修改跑出来是 69%），因为电芯是分解机做出来马上就被用掉的。用电芯的东西都没断货，这次没动。

**截图里的熏炉**：读入不丧的存档跑 5 分钟以后，三条线都在做肉松（肉松 14 个，比腊肉 81 个少）。

## 7. 屠夫放大 1.5 倍

- 模型缩放 3.8 → 5.7，大约 5.4 米高，是主角的 3 倍左右。
- 身体半径 1.15 → 1.7。挨子弹、手雷、跟主角互相推开都用新半径。
- 头顶飘字（伤害、「打断！」、技能名）跟着抬高 1.5 倍。
- 走、跑的播放速度本来就是按「移动速度 ÷（动作步幅 × 缩放）」算的，缩放改了会自动对上，脚不滑。
- 预警圈大小都没改：砸地 5.6 米，冲锋宽 2.6 米，挥刀 3.9 米。挥刀的扇形现在从身子外面（1.36 米）开始画，不再压在屠夫脚下。
- 冲锋撞人按预警长条的宽度算，不跟着身子变大，预警外面不会被撞。冲锋撞砧板照旧会停下。
- **跟掩体的碰撞留在 1.15**（脚的占地）。改成 1.4 时，屠夫过不了掩体之间的缝，会卡在后面，fbsim 用时变成 151 秒，子弹被挡 32%。脚本来就比肩膀窄，所以碰掩体还用脚的大小，挨子弹和碰人用身子的大小。
- 倒下：倒下前先挑一个方向，保证往前 4.2 米之内不压进掩体和崖壁（从现在朝的方向往两边找）。宝箱离身子远一点（2.6 → 3.9 米），再从掩体里推出来。
- 砸地的落点、尘土圈、倒地的尘土都跟着放大。

**fbsim**：200 局全赢，**中位 119.7 秒**，平均 124.0 秒，10%～90% 是 109～143 秒。在 110～130 秒的范围里。
