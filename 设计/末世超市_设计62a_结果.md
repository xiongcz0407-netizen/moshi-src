## 一、员工指定

### 怎么管
- **自动**（默认）：跟以前一样。没人管的机器 / 棚，按效率从高到低补给「自动」的人，补到他能管的台数为止。
- **指定**：只管玩家勾的那几个，最少 1 个、最多能管的台数。
  - 补人时跳过他。
  - 清理时也不动他的分配：棚里暂时没有动物也不会丢；只有机器拆了，或者人换岗、被请走，才会去掉。
  - 指定的东西全拆光了，他自动改回「自动」。
- 存档：`S.crewPin[员工 id] = true`。种地的人存成 `{ gh, orch }`，表示管不管温室、果园。

### 在哪里设
- **员工 → 工匠 / 饲养员 → 岗位页**，顶上有开关「自动 / 指定」：
  - 自动：照旧每台写谁管，可以点「换给他」。
  - 指定：列出这个岗位全部的机器或棚，每行一个勾选框，写现在谁在管（有人是指定的就写「xx（指定）管」）。勾满以后别的变灰，写「最多管 N 台」。至少要留 1 台。
  - 勾了别人在管的那台：原来那个人是自动的，就直接交出去，他会去补别的；原来那个人是指定的，先弹确认「蛋品机原来是阿宝指定管的，交给二狗？」。
- **工坊面板**：顶上写「工匠：二狗（📌指定）▾」或「阿宝（自动）▾」。点名字会展开换人列表，每个人后面写「已管几台 / 最多几台」，指定满了的人是灰的；最后一个是「自动分」。
  - 换走了某人指定的那台时，同样会先弹确认。
- **牧场**：游戏里没有单独的牧场面板，所以在棚门口的牌子上写「饲养员：xx（指定 / 自动，快 n%）」，换人在员工岗位页里换。
- **头顶名字**：指定的人名字后面有一个小图钉。

### 种地
- 种地的人也有「自动 / 指定」，指定时勾「温室」「果园」，可以两个都勾。
- 干活分三拨：
  - 自动的人和两边都勾的人：照旧「收菜 → 摘果 → 补种」，跟以前一样，旧存档的结果不变。
  - 只管温室的：只收菜、补种。
  - 只管果园的：只摘果子。
- 果园没有在岗的人管时，熟了的树牌子写「橙子 结果了　没人摘」（红框）。

### 没人管的提示
- 机器头顶写「停着：没有工匠管」（设计60 已经有了）。
- 工坊里没人管的机器，标签上有红点。
- 员工面板顶上出红色按钮「n 台机器没人管」，点了跳到工坊里第一台没人管的机器。棚没人喂时写「n 个棚没人喂」。

### 速度
- 一台机器的速度照旧只看管它的人的效率，管得少不会更快。
- 游戏说明的员工、工坊两段，还有员工面板、工坊面板的「?」都写了怎么用「指定」：只管你勾的几台，效率高的放在最要紧的机器上。

### 测试（用不丧的存档）
| 测试 | 结果 |
|---|---|
| 阿宝指定只管蛋品机，别人自动 | 阿宝只管蛋品机；他原来管的 4 台被翠花、小林补上 ✓ |
| 阿宝饿了 | 蛋品机停，写「工匠饿了」；别人不顶上 ✓ |
| 小林（指定）勾阿宝指定的蛋品机 | 弹确认，确认后交给小林；阿宝一台都没了，改回自动 ✓ |
| 阿宝改回自动 | 被补满 ✓ |
| 指定的人换岗 / 被请走 | 指定去掉，不报错 ✓ |
| 拆掉指定的那台机器 | 去掉，没有了就改回自动，不报错 ✓ |
| 饲养员阿芳指定只管鸡棚 | 阿娟（史诗，最多 4 个）管 4 个，羊棚没人管；提示「1 个棚没人喂」 ✓ |

| 种地：都只管温室 | 果树一直不摘，牌子写「没人摘」 ✓ |

## 二、拾荒者 5 件加高

- **拾荒者 5 件：全部伤害 +30% → +65%**。4 件不变：全部伤害 +10%、减伤 +10%。
- **猎杀者不用动**：4 件全部伤害 +10%，5 件 +30%。
- 为什么是 65：12 星时要 ≥ 63 才能过「× 1.05」这一条，取 65 留一点余量。

tools/fbset.mjs 验收结果：

| 星数 | 拾荒者 5 件 ÷（拾荒者 4 件 + 1～5 关最好的传说），比「输出 × 有效生命」，要 ≥ 1.05 | 猎杀者 5 件 ÷ 拾荒者 5 件，比「打 BOSS 输出」，要 ≥ 1.15 |
|---|---|---|
| 0 | 1.315 ✓ | 3372 ÷ 2074 = 1.626 ✓ |
| 6 | 1.188 ✓ | 5725 ÷ 2502 = 2.288 ✓ |
| 9 | 1.126 ✓ | 7414 ÷ 2733 = 2.713 ✓ |
| 12 | 1.069 ✓ | 9566 ÷ 2972 = 3.218 ✓ |

- 改之前（+30%）这一条只有 1.052 / 0.950 / 0.901 / 0.855，6、9、12 星都没过。
- 猎杀者原来那两条验收也照旧都过：5 件 ÷（4 件 + 鹰眼头盔）在 1.056～1.108；（4 件 + 传说）÷ 散装在 1.30～1.39。
- fbset 新加了第 2 条验收。fbtest 加了一项「拾荒者 5 件 +65%、4 件 +10%」，共 41 项全过。
- 装备页的套装说明是从配置里直接读的，现在写「5 件　全部伤害 +65%」。
- 截图时顺手修了一个问题：装备详情里的「伤害 +61.900000000000006%」，现在会四舍五入到一位小数。

## 三、屠夫狂暴的样子

- 去掉了原来那层很强的红色自发光，就是它把贴图盖成了粉红色剪影。现在身上只有很淡的一层红，贴图都看得见。
- 外面加了一圈红色描边：用同一副骨头的外扩反面壳，粗细和透明度一明一暗地变（每秒约 1 次）。
- 脚下加了一圈红光，用光效 2×2 第 4 格（光圈）染成红色，大小也跟着一明一暗。
- 击败以后描边和光圈都关掉。
