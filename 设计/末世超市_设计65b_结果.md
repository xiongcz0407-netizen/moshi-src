# 设计65b：修 65a 改坏的地面 —— 结果（V4.91）

版本：V4.81 → **V4.91**（APP_V 491）。存档格式没变。
截图：`美术/检查截图/1022_设计65/`，文件名以 `65b_` 开头。

## 原因（3 个，第 1 个是变黑的直接原因）

65a 把工坊石板地、东北商人空地、货车泥地各合成了「一个网格、外圈用顶点透明度」。新网格的 UV 是对的，顶点颜色的 rgb 也是 1（白），问题出在下面三处：

1. **三角形是反的，法线被翻成朝下（变黑就是这个）**
   - 填充用 `ShapeUtils.triangulateShape` 在 (x, z) 平面上切三角形，切出来的三角形从上往下看是顺时针，也就是背面朝上。我写了个脚本数过：工坊那块 118 个三角形，118 个都朝下。
   - 材质又开了两面画（DoubleSide）。three 画背面时会把法线翻过来，结果法线朝下，太阳光照不到，只剩一点环境光，所以整块成了深墨绿 / 黑色。
2. **直边标记写错了，整圈都没有渐变边**
   - 直边的点用 `.flat` 做标记，可是数组自带一个 `flat()` 方法，所以每个点读出来都是「真」。
   - 结果每个点都被当成直边，外圈宽度全是 0，整圈都没有慢慢透明接草地。
   - 65a 的 ground_scan 是 0 对，也跟这个有关：外圈根本没铺出来。
3. **整块标成了半透明**
   - 填充也跟着变成半透明材质，放到最后一遍画。
   - 人、箱子脚下的软影子会被它盖掉，贴图看起来也偏淡。

## 改法

- **三角形一律朝上**：每个三角形算一下朝向，朝下的就把顶点顺序换过来；材质改回只画正面。
- **标记改名**：直边标记改叫 `.fl`，外圈渐变回来了，宽 0.2～0.5 米，宽窄不一，跟 V4.71 一样。
- **还是一个网格，分两组材质画**：
  - 填充：不透明，跟 V4.71 的填充同一种材质，跟路一样在不透明那一遍画；
  - 外圈：顶点透明度、不写深度，跟 V4.71 的外圈一样。
  - 形状上还是一层，填充和外圈不叠。
- **分层和检查跟上**：分层（layerGround）和 ground_scan 原来只认单个材质，这次改成也认「一个网格两组材质」。两组材质用同一个分层高度，64a 的分层保留。

65a 的路口对齐、直边、单层都保留。

### 顺带发现、这次没动的
64a 的分层要先复制一份材质，而复制不会带上 `onBeforeCompile`。所以路、石板地、泥地这些贴片原来的云影、深浅、打破重复的效果其实早就没了。查下来 V4.61 时这些贴片就已经没有这层效果，不是 64a 才开始的。

我试过把它加回去：石板地上会叠出一层转了角度的大石板花纹，跟现在看惯的样子不一样。所以这次保持原样，没有加回去。要加的话可以单独说。

## 检查
- **ground_scan**：超市 41 块贴片，叠在一起的还是只剩湖面那 4 对（浅水、深水跟亮纹、白浪），跟 65a 一样。俯视图 `65b_ground_scan.png` 里能看到三块地的外圈渐变（边是波浪的）。
- **对比截图**：6 张，同一个存档（xiongcz2）、同一个位置，左边 V4.71、右边 V4.91：
  - 石板地看得到一块块石板，泥地看得到泥土贴图；
  - 边上慢慢透明接草地，亮度跟旁边的路一样；
  - 脚下的软影子也在。
  - 左右两张镜头差一点，是因为截图时主角刚瞬移过去，镜头还在追。
- lint 0 错误；fbtest 41 项通过；core2、tdg 通过。
