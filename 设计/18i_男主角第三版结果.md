# 18i 男主角第三版结果（10-17，发型头做法：设计 18f；截图：设计 18h）

## 一条命令
```
bash tools/people3/run.sh 配置.json "这次改了什么"
```
配置（例子 cfg_example.json）写 4 个 GLB 和输出目录：body（基础身体）、head（标准头，只当尺子）、hairhead（发型头）、cloth（衣服），面数可选。
跑完自动做完下面全部：
1. hero.py（Blender）：量身体头高 → 放尺子 → 发型头按下巴上 4%～20% 那段脸宽算倍数、下巴对齐 → 头发遮罩（按颜色，小肉色斑填成头发，脸中间五官区不算）→ 减面 → 衣服对齐、删皮肤、切三件 → 身体删头 / 删衣服盖住的 / 脖子贴进头里 → 骨骼、权重、站 / 走 / 跑 → 导出 hero_m2.glb、report.json，尺子另存 ruler_check.glb（只给量比例用）。
2. check.py：正交正面渲染尺子，量 18f 的 5 个比例 → check.json。
3. 拷进游戏 src/models/people/hero_m2.glb，打包。
4. shots.mjs：在游戏里用游戏材质拍 18h 的 14 张；compose.py 拼图、写 info.txt → `检查截图/<月日_时分>_<改了什么>/` 和 `检查截图/最新/`。

**手动的只有**：
- 你把新 GLB 放进 美术/模型 并告诉我；我拷到云端、跑上面那条命令（Blender 在云端），再把截图存回 美术/检查截图/。
- info.txt 最后的「自查」几行是人看截图写的。
- 新发型如果头发颜色很特别（比如本来就是肉色、或者带彩色挑染），遮罩可能要调参数。

## 这版改的
- 换发型 = 换整颗发型头（头发 + 脸），不再剪头发、套标准头。
- 只染头发：贴图透明通道 = 头发遮罩，脸、眉毛、眼睛、耳朵不染。鬓角原来有一条没染的灰条（被当成五官区）：五官区改成只算脸中间。
- 脖子：原来身体头的下沿（下颌底、后脑勺下沿）比发型头凸出来，从侧面 / 背面看是一圈锯齿 → 改成把这些顶点贴进发型头里面 4 毫米，不删不加面，脖子直接连到头上；脖子和领口里涂成脸的肤色（原来身体后颈有头发贴图、胸口是白背心）。
- 截图工具：相机只拍主角（不会拍到货架）；14 游戏里改成 7 米、正面、平视。
