# 设计29e：29d 做完的结果（V2.31）

## 一、29c 的问题
1. **详情区的字被截掉**：原因是详情区的说明用了「最多 3 行 / 2 行，多的打省略号」。现在详情区里所有文字都完整显示（去掉了省略号、行数限制、不换行）。太长的改短：建造 → 超市只写「解锁 10 种新商品（名单看「?」）」，名单放进「?」；工坊腌菜缸 7 种原料改成图标格子。
   自动检查加了一条：详情区（和设置页）里任何带字的元素，只要设了省略号 / 隐藏溢出 / 行数限制，并且内容比框大，就算不通过。这次两个尺寸、所有面板、每个页签每一格都点过，都通过。
2. **施工队忙时按钮要变灰**：以前这些按钮用的是「浅色按钮」样式，禁用时颜色没变。现在面板里所有不能点的按钮（包括浅色的）都是统一的灰色，和建造详情里「施工队都在忙」一样（货架升档、塔位 4 个塔按钮、施肥、开始做……）。
3. **星星兑换 5000 末日币**：加了末日币图标和「×5000」角标。
4. **货架选货缺罐头和绷带**：是「同一种货只能摆一个货柜」（V1.11 你定的，logic 里 setShelf 也这样限制），不是 bug。现在别的货柜在卖的货也列出来，变灰、不能点，写「3号在卖」（同一个果蔬架别的格在卖写「第2种」）。
5. 员工头像重复：没改，记下了。

## 二、第三批
- **尸潮**：页签 普通本 / 英雄本（没开写 🔒，点进去写「普通第 10 关打赢才开英雄本」）。资源条：尸潮卷数量、「今天 5/5」。页签那一行右边：经验（超市升级要多少）和「买 1 张尸潮卷」。10 关 5 × 2 格子：关卡号、几波、状态（✓ 打赢过 / 能打 / 🔒 原因）；有保底没打赢过的贴「必得史诗 / 必得传说」。详情：几波、丧尸血倍数、Boss（几个 Boss、小 Boss）、打赢奖励（XP / 末日币 / 工具箱图标加数字，打赢过写「打赢过，奖励减半」并显示减半后的数）、员工（普通本：必得或「史诗 x%　传说 y%」；英雄本不写）、「开打 用 1 张尸潮卷」按钮，打不了变灰并写原因。英雄本说明、玩法说明在「?」。
- **温室**：页签 温室 / 果园（盖了果园才有）。一块地 / 一棵树一格：作物图标、进度条、还要多久或「熟了」（贴「能收」）。没选格子时右边是「选一种种子，把空地全种上」。点空地：种子图标格子（仓库没这种种子的变灰），有种地员工时还有「员工补种」。点种着的：还要多久、进度条、收获几个、施肥按钮（没肥料变灰）。果园空树位选树苗，种着的可以换种别的树。「全部收获 N」在页签那一行右边，没熟的时候变灰。
- **工坊**：一台机器一个页签（没盖的不显示；没东西做的厨房写超市几级开放）。页签下面一条：机器几级、每条线在做什么（图标、进度、还要几秒）/ 空着 / 做好了仓库放不下、有没有工匠管。一个配方一格：成品、原料图标（不够的红）、用时；原料不够的变灰。详情：原料每样「有 x / 要 y」（机器是任选一种，用图标格子写「有 x」）、做几个（−1 / +1，最多到空线数和原料数）、「开始做」、「工匠只做这个 / 工匠改回自动」。
- **设置**：现有的设置项里没有声音设置，所以没有「声音」页签。页签：游戏（外观店名、省电模式开关）、账号（云端存档、换存档）、数据（这个存档的统计）、说明（游戏说明，左边选题目、右边看）、关于（版本 / 更新、更新记录）。每项一行，按钮和开关在右边。**更新记录和游戏说明在固定高度的框里上下滑**（游戏说明内容太长，一屏放不下，跟更新记录一样处理）。原来单独的「开发者说明」「我的数据」页还留着（从别处打开时用）。
- **删竖屏代码**：去掉了只在竖屏才会用到的样式（宽度 640 以下的排版）和注释里的竖屏说明（创建人物页的竖屏排法 V2.11 已删）。**留下了「请把手机横过来」的提示和竖着时游戏暂停**——这是让游戏只能横屏玩的那部分，删了竖着拿手机会看到挤坏的横屏界面。如果你也要删，告诉我。
