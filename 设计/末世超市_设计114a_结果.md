## 技能（全部在 `fbcore.js` 的 `SCREAM_CFG` / `screamStep`）
| 招式 | 做成什么样 |
|---|---|
| 鸦弹 | 抬手，BOSS 到主角一条 1 米宽的长条，0.7 秒；手里飞出一只乌鸦。掩体挡住就撞在掩体上散羽毛。安静时间里每 1.6 秒一次（嗜血 1.12 秒，一次 3 只、扇形 20°、每只 0.4） |
| 闪现 | 起点黑紫烟 + 羽毛，落点先出黑影 0.3 秒。A：闪到离主角 6～10 米，**尽量在主角北边**（镜头往北看，脸在画面里）；B：闪到主角身前 2 米 → 鸦群喷射（扇形半径 4、70°，0.55 秒）→ 喷完马上闪 A。每 4～6 秒一次（嗜血 2.5～3.5 秒），B 占 40%（嗜血 50%）；主角走到 4 米内马上闪 A。落点不出场地、不进掩体、不压喇叭杆（fbtest 跑 2 分钟验过） |
| 声波三环 | 仰头尖叫 1 秒，脚下 3 道环一道一道往外扩（每秒 7 米、间隔 0.6 秒），每道一个 50° 缺口（嗜血 35°），掩体挡不住，翻滚无敌能穿 |
| 喇叭音爆 | 冲着离主角最近的没坏的喇叭尖啸，喇叭前一大片扇形（半径 11、60°，1.4 秒），喇叭抖；打中扣血 + 往外推 3 米，推到女儿墙再扣 0.3。能打断（那个喇叭这下不响）。喇叭全坏了换成声波三环 |
| 乌鸦群 | 张开双臂，场地一条 4 米宽的横带（1.3 秒），乌鸦群横扫过去；扫完留 3 只小乌鸦绕着主角飞、啄（每只每秒 0.08），普攻优先打它们。嗜血时多一条竖带交叉。能打断 |
| 刺耳尖叫 | 施法条「刺耳尖叫（全场）」1.5 秒，画面边缘慢慢泛紫；全场扣 90（必吃，翻滚也挡不住）→ **错乱 2 秒**：摇杆全反（走路、翻滚都反）；头顶紫色漩涡、左上角「错乱 1.6」、画面边缘紫色一圈。错乱完 2 秒内不再错乱。尖叫后一定接一次闪现 B |
| 广播轰炸（大招） | 红色施法条 2 秒，BOSS 闪上信号塔半腰（离地 4 米），没坏的喇叭一起抖；之后顺时针（西北 → 东北 → 东南 → 西南）每 0.8 秒一个喇叭音爆（每个先亮 1 秒预警），最后塔上放一道全场声波环（有缺口，大招 × 0.6）；放完闪回地面。喇叭坏得越多越弱 |
| 半血嗜血 | 抱头尖叫 1.8 秒，身上暗红、脚下暗红光环、身边红雾，乌鸦换红眼图；伤害 × 1.25，闪现更勤，鸦弹 3 只，没坏的喇叭修好回满血（坏了的还是坏的），乌鸦群两条带，缺口 35° |
| 灭杀 | 跟前三关一样（106）。BOSS 先回到地上、喇叭全修好；打下来时全部喇叭 + 信号塔一起轰、漫天红眼乌鸦、画面全白闪；期间 BOSS 不掉血（fbtest 验过） |

- 出招顺序照文档：声波三环 → 乌鸦群 → 喇叭音爆 → 刺耳尖叫 → 声波三环 → 喇叭音爆 → 广播轰炸 → 乌鸦群（循环），每 6 秒一招（嗜血 5 秒），第一招开场 3 秒后，招和招之间安静 1.8 秒。
- 站位：离主角超过 11 米就慢慢走过来，平时站着扔鸦弹。
- 打断不了的（声波三环、刺耳尖叫、广播轰炸、闪现、鸦弹）被震荡弹打中只慢 50%。

### 跟文档不一样的地方（请设计看）
1. **声波三环的缺口不是完全随机**：完全随机时，第 2、3 道的缺口常常在主角背后半圈（离 7 米要走十几米），根本走不过去，只能翻滚，翻滚又有冷却，机器人 3 道吃 2 道。现在：
   - 第 1 道缺口在主角那边偏 9～26°；
   - 后面每道往同一边挪 26～34°，缺口 50°，前后两道的缺口有一点重叠，跟着走得过去；
   - 读条的 1 秒里，BOSS 脚下先淡淡画出 3 道环的缺口位置（截图「声波三环_读条看缺口」）。
2. **血量、伤害调了**：文档先用 150000 / 380。
   - 150000 时全攻击走位好只有 7～40%，过不了；
   - 现在 **血量 140000、普通技能 500**（大招 640 没动），声波环系数 0.9 → 1.1。
3. 鸦弹不显示施法条（太频繁，一直闪会挡别的招）。
