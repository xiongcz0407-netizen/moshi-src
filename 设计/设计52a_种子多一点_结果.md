# 设计52a：种子多一点（V4.01）

## 改法
1. 种子来源（bonusSeed 不动，还是 0.6）：
   - 拾荒员工每趟带回的种子 STAFF.scav.seeds：8～11 → **11～15** 包；
   - 顾客结账多给一包的机会 FARM.tipSeed：0.05 → **0.08**。
   - 新的种子还是按 seedW 抽。
2. seedW 微调（结束时这两种偏少）：
   - 南瓜 13 → **16**；
   - 松茸 13 → **22**。
3. **加了一处补种规则，要你知道**：
   - 第一次跑（只加种子）：4 级货柜反而有空的。连跑三次：萝卜 3.8%、2.2%，胡萝卜 5.8%，腌萝卜 3.4%；51a 时都是 0%。
   - 原因：种子够了以后，「收完种回同一种」每次都成功，地就一直锁在最早种的那几样上。没被种上的菜（胡萝卜、萝卜）货柜会空。以前种子常用完，地才会换种别的。
   - **改法**：收完补种时，如果有别的菜（有种子、仓库没快满），它的货柜 + 仓库不到这种的一半，就改种那种最少的。
   - 这种没种子或者快满时，还是按 51 空着等下一件事。
   - 改了以后，货柜是 0 的时间回到全部 0%。
