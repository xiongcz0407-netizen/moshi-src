# 设计88a：炼宝页 4 处改动 —— 结果（V7.71 → V7.81）

版本：**V7.81**（APP_V 781）。存档格式没变。
截图：`美术/检查截图/1024_设计88/`

## 1. 右边详情一直显示装备属性
- **顶上**：大图标、名字（品质色）、品质 · 最高几星、星星那一排。
  - 图标改成放在名字左边，省出高度给属性：844 宽 50px，667 宽 46px。
- **属性一块一直显示**：
  - 没满星：每行「属性名　现在 → 下一星」，下一星绿色；
  - 满星：每行「属性名　现在的值」，没有箭头，底下小字「最高 N 星，满了」；
  - 顺序照旧，主属性在前，词条在后。
- **滚动**：只有属性这一块能上下滚，顶上和底下的炼宝栏不动。
  - 实测：844、667 两种宽度下，4 行属性都不用滚就能看全。

## 2. 炼宝栏固定在底部
- 跟副本面板「挑战」那一栏同一种样式：
  - 左边两行：「升到 N 星　成功率 xx%（保底 +x%）」和「💎 花费（有 N）」；
  - 右边是「炼宝」按钮。
  - 晶石不够时那一行变红。
- **按钮变灰**：晶石不够、动画放着时都是灰的。实测晶石 0 时按钮是灰的。
- **满星**：这一栏写「已满星」，按钮灰着，整栏不消失。
- **位置**：844、667 两种宽度，按钮都在详情框里，不用往下拉。
  - 844 宽：按钮底边 340，框底 360；
  - 667 宽：按钮底边 325，框底 345。

## 3. 炼宝成功显示属性变化
- 「炼宝成功！★ N 星」下面列这次变化的属性：「属性名　旧值 → 新值 ↑」，新值绿色。
- 只列有变化的，最多 4 行，多了写「…还有 N 项」。
- 有属性行的时候，大字从 30 缩到 26px，整块放在铁砧原来的位置，不盖住装备图标。
  - 844 宽：文字顶 245、图标底 239，文字底 374、框底 380；
  - 667 宽：文字底 360、框底 365。
- 失败照旧：「失败了 / 星星没掉 / 下次成功率 +5%」，不列属性。
- 星星飞进右边那一排时，右边详情马上换成新属性。

## 4. 炼宝动画不能被点掉，要放完
- 去掉了「点一下跳过」。敲打、出结果整段动画放的时候，点屏幕不理。
- 放完停在结果上，不再自己关掉。结果出来 0.5 秒以后，右下角出现「点一下关闭」，点一下才淡出关掉。
- 动画放着、结果停着的时候，「炼宝」按钮一直是灰的。关掉以后按钮能点，右边详情已经是新属性。

### 连点测试（虚拟时间，每帧 1/60 秒；844、667 两种宽度结果一样）
| 测试 | 结果 |
|---|---|
| 动画中连点 10 下（每 0.15 秒一下，从 0.05 秒点到 1.5 秒） | 动画时间照走：0.2 → 0.35 → … → 1.55 秒，没有被跳过；按钮灰 |
| 放完以后又等 2.5 秒 | 还开着，停在结果上（t = 2.2）；「点一下关闭」亮了；画面里没有「跳过」 |
| 结果出来 0.3 秒时点 | 不关 |
| 结果出来 0.6 秒时点 | 关了 |
| 关掉以后 | 右边属性已经是新值（伤害 17.6% → 18.7%），按钮能点 |
