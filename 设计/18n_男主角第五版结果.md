## 改了哪些文件
- tools/people3/hero.py：头发遮罩和身体皮肤遮罩改放顶点颜色，贴图不再带透明通道；脖子重做成圆柱（粗细 = 脸宽 35%～31%，下端插进领口、上端按发型头底面融进去，平滑法线）；上衣下摆往下盖住裤腰 1.5 厘米、裤腰往里收；裤子 / 上衣去掉错传的手臂权重（跑步时裤子被手带飞），裤腰跟胯走；走、跑动作按设计 18m 重做，并算出每个动作的地面速度。
- tools/people3/texfix.py：发型头贴图存成 RGB（不带透明通道），头发遮罩另存一份给 hero.py 写进顶点颜色。
- tools/people3/shots.mjs：14_游戏里 改成真游戏正常玩的画面（游戏自己的相机、灯光、界面）；加 15_跑步_正面（4 帧）。
- tools/people3/compose.py：拼 15_跑步_正面；info.txt 末尾加「改了哪些文件」（读输出目录的 changes.json）。
- src/js/hero2.js：身体、发型头的材质改读顶点颜色当遮罩（不用贴图透明通道）；脖子不再关法线贴图和高光；记下动作的地面速度。
- src/js/chars.js：站 / 走 / 跑按速度切，0.18 秒过渡；播放速度 = 实际速度 ÷ 动作的地面速度，脚不打滑。
- src/js/creator.js：创建人物按设计 18l 重写：预览固定、分页（发型 / 上衣 / 裤子 / 鞋）、每页款式一排 + 颜色一排横向滑；点选项只改高亮和预览，不重建列表；拖预览能转人物。
- src/js/main.js：创建人物时竖屏也能用（人物在上半屏），预览跟着拖动转。
- src/style.css：创建人物新布局（横屏左右、竖屏上下），创建人物时不显示「请横屏」。
- src/js/changelog.js、src/js/help.js：加这次的更新说明。
