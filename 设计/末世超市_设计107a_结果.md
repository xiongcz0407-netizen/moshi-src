## 1. 模型（`tools/smith_rig/`）
- `铁匠.glb`（5 万面、3 张 4096 图、30 MB）→ `src/models/npc/smith.glb` **0.27 MB**：减面到 **5000 三角面**，只留颜色贴图、压到 1024，绑 19 根骨（跟落石巨人一样：体素代理自动权重，再传回原模型、修串错的点）。
- 3 个动作（30 帧）：**idle 待机敲铁砧**（1.6 秒一下：右手举起 → 停 → 砸下去 → 停在砧上 → 抬起，左手扶着工件，循环）、**wipe 擦汗**（3 秒，左手抬到额头抹一下）、**wave 挥手招呼**（2 秒，右手举过头左右摆）。
- `铁匠摊.glb`（5 万面、36 MB）→ `src/models/npc/smith_stall.glb` **0.21 MB**：减面到 **4000 三角面**，颜色贴图 1024；贴图里很黄绿的地皮边缘压暗、偏土色。
- 两个都用 `tools/glbpress.mjs` 压过（meshopt）。原版还在 `美术/模型/铁匠/`，**没另外放 `_hi` 版**（游戏里没有用到 `_hi`，要的话再出）。
- 脚本：`rigbuild.py`（减面、贴图、绑骨）、`joints.py`（关节）、`anim.py` + `poses.py`（动作、导出）、`stall.py`（摊子）。要用 `pip install bpy`；注意别在放了 `inspect.py` 的目录里跑（会跟 Python 自带的 inspect 撞名，bpy 报 InitGoogleLogging twice）。
- 大小：铁匠 ×1.83（约 2 米，跟主角一样高），摊子 ×2.6（铁砧大约到他腰）。炉子上加了两层叠加的光斑轻轻跳（一张贴图、两个精灵）。

## 2. 摆放和出现
- `world.js`：`SMITH_POS = (-16.6, -22.2)`——传送门西边、北边围栏前的草地。离传送门正面约 5.7 米、离院子商人约 10 米、离回收机约 9.5 米，「找铁匠」和「进商店」不会同时出，也不挡石板路、传送门。摊子在他身前偏右（铁砧在他右手前面）。
- `main.js`：超市 **5 级（`FB.store`）才摆出来**，那时才加碰撞（摊子一块 + 人一块）；超市低于 5 级（GM 改档）会收走、碰撞也拿掉。升到 5 级时 2 秒后提示一次「铁匠来了：炼宝、传说转换找他（传送门旁边）」（也进消息）。
- 模型进游戏以后在后台读（跟院子商人一样），在「基础」包里。
- 尸潮时跟院子商人一样：人还在，按钮不出。

## 3. 交互
- 走到铁匠 3.4 米以内：右下角「找铁匠」（跟「进商店」同一个位置、同一种按钮，`#smithBtn` 在 main.js 里照「进商店」复制出来），点了打开 `smith` 面板（炼宝 | 传说转换）。走近时挥一次手；离开 5 米再回来会再挥。
- 平时循环敲铁砧，每 15～25 秒擦一次汗（人在旁边时不擦）。
- 头顶不写名字；`toSmith()` 时头顶出跟商人一样的闪动箭头 3 秒。
- 铁匠面板里也放炼宝敲打动画（`fbRefine` 原来只认角色页）。
- 传说转换：`fbLegSwap` → 确认框「花 2000 末日币，把 岩心 随机换成同一关的另一种传说？」→ 结果框 + 光效，1.7 秒后按钮恢复。
- 0★ 传说点「炼宝」先确认「XX 升星后就不能做传说转换了。确定炼宝？」（105b 补充）。

## 4. 拿掉旧入口
- `ui.js`：角色页页签去掉「炼宝」，剩 **主角 | 装备 | 背包 | 技能**（超市 5 级前锁着的那排也去掉炼宝）；商人补给页晶石说明改成「炼宝（找铁匠给装备升星）用」。菜单里本来就没有炼宝入口。
- `fbui.js`：装备 / 背包详情的「去炼宝」→「**去铁匠那里炼宝**」；背包里的传说多一个「**去铁匠那里转换**」；点了关面板、提示「炼宝找铁匠（传送门旁边）」/「传说转换找铁匠（传送门旁边）」、铁匠头顶闪。装备页「?」说明改成「炼宝：找铁匠（传送门旁边）……传说没升过星时，可以在铁匠那里转换」。老的跳到角色页炼宝页签的地方改看装备页。
- 副本面板的说明里本来没写炼宝，没改。

## 测试
- 浏览器实测（`tools/test/s_smith.mjs`，844 和 667 各一次）：
  - 超市 5 级有铁匠，3 个动作都在；走近「找铁匠」出现、挥手在放；走远按钮消失；点按钮打开铁匠面板。
  - 角色页页签「主角 | 装备 | 背包 2/30 | 技能」，没有炼宝。
  - 点「去铁匠那里炼宝」：关面板、提示、铁匠头顶闪。
  - 改成超市 4 级：铁匠收走、碰撞拿掉、没有按钮。
  - 两个尺寸都没有报错。
- 105b 的转换：真点「转换」→ 确认 → 结果框，扣 2000、换成另一种、掉落记录 `swap` 对。
- fbtest 42、fblogtest 9、fb105test 32 项全过；lint 0 错误；打包正常。
- **性能**：测试机是软件渲染（帧数本来就很低），同一个位置有铁匠 3.7 帧 / 超市 4 级没有铁匠 3.8 帧（844）、4.4 / 4.7（667），差别在误差里。加的东西：约 9000 三角面、一个骨骼动画（19 根骨）、两个光斑精灵、两个模型合计 0.5 MB。真手机上的帧数请主开发顺手看一下性能小窗。
