# 设计69a：头顶牌子闪烁 + 走近了才显示 —— 结果（V5.31）

版本：V5.21 → **V5.31**（APP_V 531）。存档格式没变。设计70 接着做了，所以上线包是 V5.41，两份一起进去。
截图 / 录屏：`美术/检查截图/1022_设计69/`

## 一、为什么闪
以前的避让每 48 毫秒从头重算一遍，没有记性。下面几种情况，牌子就在「原地 / 往上挪一格 / 先不画」之间来回换：
- 顾客、员工的名字牌走过来压到货柜牌子；
- 主角走两步，「最近 3 个能升级的」换了一个；
- 「缺货」随卖掉、补货一会儿有一会儿没有。

## 二、改法（ui.js 牌子重写，main.js 配合）
- **固定的先放，会走的让开**
  - 先放：货柜、机器、温室、棚、升级箭头、建筑；
  - 后放：人和动物的名字（mob）。
  - 会走的压到固定的，只让会走的挪开或先不画。
- **有记性**
  - 上次的位置还空着就不挪；
  - 被挤开的，原位置连续空 0.5 秒才搬回去；
  - 藏起来的，连续有地方 0.5 秒才显示；
  - 显示着的，连续放不下 0.3 秒才藏。
- **淡入淡出**：显示 / 藏用 0.15 秒淡入淡出，挤开 / 搬回用 0.12 秒滑过去。跟着画面走的位置还是每帧算，不加过渡，设计66 的不抖不受影响。
- **宽度**：按「数字换成 0 以后一样」的内容记最宽的那次。倒计时、排队数在变时，不会因为宽度变了重新排。
- **货柜「缺货」**：缺货变没了也先留 1.5 秒，补一个卖一个时不闪。
- **升级箭头**
  - 变没了先留 1 秒；
  - 已经画着的优先留着：近 1.5 米以内算它更近，主角走两步不会一会儿这个一会儿那个。

## 三、走近了才显示（设置 → 头顶牌子：「只显示附近的」默认 /「全部显示」）
| 牌子 | 什么时候显示 |
|---|---|
| 店里的货柜、收银员 | 主角进了超市 |
| 工坊机器 | 在工坊石板地上（离主角最近 3 台、5 米内，照旧） |
| 温室、果园 | 在里面或 2 米内 |
| 牧场的棚 | 在牧场走道上，且离这个棚 6 米内 |
| 池塘、码头 | 4 米内 |
| 东北角商人、传送门 | 在那块空地上 |
| 回收机、宿舍、仓库、塔、施工 | 5 米内 |
| 院子里的员工、顾客 | 5 米内 |

- 场地边上留 1 米缓冲。进来马上显示，出去 0.5 秒后才藏。
- 顶栏、按钮、尸潮里的牌子不受影响。尸潮、布置、出门拾荒时照旧全部显示。
- **紧急提醒在哪都看得到**，走近才展开成字：
  - 员工饿了：小饭碗；
  - 机器没人管、在等原料停着：小红点（每秒算一次）。
- 文档里的「施工完成 !」没做：现在施工到时间自动完成，没有「完成了等你点」的状态。

## 四、测的结果（xiongcz2 存档，虚拟时间 60 赫兹，一帧一帧记每个牌子显示没显示）
| 场景 | 改前：显示 ↔ 不显示来回换了几次 | 改后 |
|---|---|---|
| 店里站 6 秒，鱼一会儿缺货一会儿有（每 0.33 秒换一次），钱一会儿够升级一会儿不够（每 0.5 秒） | **鱼 缺货 17 次、⬆ 11 次**、回收机 11 次 | **0** |
| 店里来回走 8 秒 | 秀兰（收银）7 次、回收机 7 次 | **0** |
| 店里站 30 秒（正常卖货） | 回收机 8 次 | **0** |

- 改后，「鱼 缺货」挤开、搬回各滑了一次（8 秒里 3 帧）。
- 测试脚本里的「牌子位置误差」改后会显示 132 像素，不是真的错位：避让偏移改用 CSS `translate` 属性单独写了，脚本还按旧写法把偏移算进去了。去掉偏移以后，误差跟改前一样是 0.05 像素。
