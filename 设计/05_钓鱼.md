## 1. 已定的规则

| 项目 | 定了什么 |
|---|---|
| 开放 | 超市 3 级 |
| 入口 | 院子西南角（果园南边的空地）一个小水塘 + 木栈桥 + 小渔船，走上栈桥出现「坐船去钓鱼」。原来警报器那块在小路上、太窄，放不下码头，所以挪到西南角 |
| 垂钓证 | 500 末日币，买一次永久有效；第一次在码头点「坐船」时没证就弹出购买，商城里也能买 |
| 船费 | 每趟 100 末日币 |
| 地图 | 单独一张小地图（像拾荒区，进出有读取界面），湖 / 河边，没有丧尸，安静地钓 |
| 区域 | 近岸 / 深水 / 桥下 3 块，每块有几个钓鱼点；不同区域出的鱼不一样 |
| 操作 | 走到钓鱼点 → 抛竿 → 等咬钩 → 拉力条小游戏（按住 / 松开，把指针保持在绿区，坚持一会儿就钓上来；越稀有越难） |
| 饵料 | 蚯蚓、玉米饵两种；每抛一竿用 1 个；近岸用蚯蚓、深水用玉米饵、桥下两种都行（引来的鱼不一样）；饵不对或没饵不能抛竿；饵料不占背包格子（和发条一样算道具） |
| 鱼竿 | 「建造」里升级鱼竿 1～3 级（占施工队）：拉力条更好控制、更容易钓到稀有鱼。鱼竿有耐久：每钓上一条掉 1，拉断了掉更多；耐久 0 不能钓，买「新鱼竿」补满耐久（等级保留），价格看等级 |
| 商人 | 院子里一个（医院东边、小路旁）、钓鱼区里一个（船旁边），点开就是商城页面（钓鱼区的贵 20%）；卖饵料、新鱼竿，原来商城的东西也在 |
| 背包 | 同一种鱼一格叠 20 条（和别的东西一样） |
| 一趟怎么结束 | 背包满了或者自己点「回去」 |
| 卖鱼 | 带回超市进仓库；冰柜的一种货可以选「鱼」，仓库里的鱼按顺序自动补上去（各种鱼混着放）；顾客只说要买鱼、不挑哪种，买走一条按那条鱼的价钱算 |
| 保鲜 | 不会坏 |
| 以后（超市 4 级） | 超市里挖池塘、放鱼苗——这次不做 |

## 2. 价格（用户确认）

- 垂钓证 500（一次）；船费 100 / 趟
- 蚯蚓 5 / 个、玉米饵 8 / 个（买 20 个打折）
- 新鱼竿：1 级 150、2 级 300、3 级 500；耐久 30 / 40 / 50 条
- 鱼卖 8～120 不等，传说鱼 300
- 钓鱼区商人比院子里贵 20%

## 3. 鱼（14 种，先这么定）

| 区域 | 饵 | 鱼（售价） |
|---|---|---|
| 近岸 | 蚯蚓 | 常见：鲫鱼 8、草鱼 12；少见：鲤鱼 18、黄颡鱼 22；稀有：鳜鱼 45 |
| 深水 | 玉米饵 | 常见：鲢鱼 14、鳙鱼 18；少见：鲈鱼 35、青鱼 40；稀有：鳡鱼 70 |
| 桥下 | 蚯蚓 | 少见：鲶鱼 32、黑鱼 40 |
| 桥下 | 玉米饵 | 稀有：鲟鱼 120 |
| 桥下 | 两种都行 | 传说：金鱼王 300（很少见） |

越稀有拉力条越难；鱼竿等级越高，稀有鱼的机会越大。模型用 Kenney 的鱼（Survival Kit fish / fish-large、Food Kit fish）换颜色、大小区分。

## 4. 做出来的样子（0.14）

- 钓鱼区地图：北边湖、湖岸沙滩上 3 个近岸点；湖里一条木栈桥（Survival Kit 木地板），尽头和侧边 2 个深水点；东边一条南北向的河、河上木桥，桥两头岸边 3 个桥下点。船停在湖西岸，旁边是商人。
- 拉力条：按住「收线」指针往右、松开往左；绿框（鱼）会游动，指针在框里进度涨，出框进度掉；顶到最右边约 1 秒断线。
- 背包没空格时，只会钓到能叠进已有格子的鱼；背包满了**不自动回去**（用户 10-13）：在背包里点一格鱼 → 选数量 → 「丢掉」→「确定丢掉」，接着钓，或者自己回船边坐船。
- 鱼卖的时候不乘冰柜的加价（按每条鱼的价钱，紧缺时 ×1.5）。
