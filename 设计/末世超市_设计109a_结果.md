## 1. 买券选几张
- 院子商人和钓鱼区商人的补给页：「1 张 / 5 张尸潮券」「1 张 / 5 张召唤券」这 4 格，改成「尸潮券」「召唤券」各一格，格子上写单价（300 / 1000，钓鱼区召唤券 1200）。
- 详情里选数量：
  - 第一排：**−10 −5 −1 [n]**；
  - 第二排：**+1 +5 +10 最多（N）**；
  - 最下面是「**买 n 张，花 X**」按钮 → 照旧弹确认框「花 X 末日币买 n 张召唤券？」→ 买完 n 回到 1。
- n 默认 1，最少 1，最多 = 现在的钱最多能买几张；钓鱼区召唤券按 1200 算。
- 钱连 1 张都不够时：整排变灰，数字是 0，按钮写「**末日币不够（1 张要 1000）**」。
- 两格共用一个数量，换格子时回到 1；跟星星兑换的 starQty 分开存（`ticQty`）。
- **跟文档不一样的地方（请设计看）**：
  - 文档要的样子是 7 个按钮一排，再加一行「买 n 张，花 X 末日币（现在的钱最多能买 N 张）」。面板里的按钮最小 44px（手指点得到），详情那一栏一排放不下 7 个，所以分成两排。
  - 那一行说明也拿掉了：「花多少」写在买的按钮上，「最多能买几张」写在「最多（N）」上。不这样的话，844 和 667 都要往下拉才看得到「买」。
  - 说明文字也缩短了：「打副本，每关 1 张。有 N 张。」「输了不退」在 help 和副本面板里有。
- 晶石（1 / 10 / 50 颗）、饵料包没动。

## 2. 「再打一次」没券时问要不要买
- 打完那排按钮：有券写「再打一次（1 张召唤券）」，没券写「**再打一次（买 1 张召唤券）**」。
- 召唤券 0 张时点「再打一次」：
  - **钱够 1 张**：弹确认框「召唤券用完了。花 1000 末日币买 1 张，再打一次？」。点确定就买 1 张，照 5b 那样黑屏开打；点取消，留在结算界面。
  - **钱不够**：在「再打一次」按钮上面出一行提示「召唤券用完了，末日币也不够（1 张要 1000）」，**留在结算界面，不回超市**。
- **跟文档不一样的地方**：钱不够那个提示没用屏幕底部的 toast，因为它会盖住「再打一次」按钮，所以改成在按钮上面写一行（截图里能看到）。
- 有券时照旧直接开打。人在副本里，一律按院子商人价 1000 算。
- 浏览器实测（第 1 关，打输以后）：
  - 0 张、5000 钱：出确认框；点确定以后在打了，券 0 → 1 → 0，钱 5000 → 4000。
  - 0 张、300 钱：出提示，还在副本里、还是结算界面，钱没少。
