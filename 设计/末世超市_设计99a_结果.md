# 设计99a：毒囊关出生点改回铁桥 + 合并 d98 + 测试脚本进仓库 —— 结果（V8.71 → V8.81）

版本：**V8.81**（APP_V 881）。这一版同时合了 **d98**（开发2：副本掉率统一）和 **d99**。存档格式没变。
截图：`美术/检查截图/1025_设计99/`

## 1. 毒囊关从南边铁桥出生（d99）
- `fbcore.js`：去掉设计 95 加的 `ARENA.start.z = lockZ + 5.5`，出生点回到第 2 关原来的桥头（x 0, z 19）。
- 其他照旧：走过去这段毒囊不放技能、打不到、不计时；走到封线（z −5）才锁死、开始计时、升毒雾墙。
- **测试**（虚拟时间，每帧 1/60 秒，主角 5 米/秒往北走）：

| 时刻 | 主角 | 锁了 | 计时 | 毒囊放过技能 |
|---|---|---|---|---|
| 传送进来 | (0, 19.0) 桥头 | 否 | 0.0 | 0 次 |
| 走到封线前一刻 | (0, −4.7) | 否 | 0.0 | 0 次 |
| 刚锁死 | (0, −5.4) | 是 | 0.2 秒 | 0 次 |

- 从桥头走到封线用 4.7 秒。一路上镜头每帧最多挪 0.083 米，跟主角走路一样快，没有跳、没有卡。镜头从桥头看过去，毒囊在远处；走近了脸进画面。

## 2. 合并 d98（开发2，设计 98）
- `Claude outputs/_d98/d98.bundle` 先推到 `origin/d98`，再 `--no-ff` 合进 main。只改了 `fbcfg.js` 的 `DROP`：所有关卡 普通 66% / 史诗 25% / 套装 3% / 传说 6%。跟 d99 没有冲突。
- fbtest 里原来「普通 60%」的期望改成 66 / 25 / 3 / 6（套装 ±1.5%、传说 ±2%，抽 4000 次）。合并后 42 项全过。
