# 设计51a：温室少空地（V3.91）

## 改法
1. **收完马上补种**（logic.js replantSeed）：
   - 种地员工收完一块地，接着种回同一种，收和种算一件事。条件是仓库里有这种菜的种子、这种菜仓库没到 80%。
   - 这块地指定了种什么：有这种种子就种指定的。
   - 种子没了或者仓库快满：空着，等下一件事（还是原来的「挑一种种上」）。
   - 果树不变；主角自己走过去收菜也不变。
   - 补种不再单独飘「种下××」，只飘收菜的字，免得同一块地上叠两行。
2. **FARM.bonusSeed 0.4 → 0.6**。跑出来南瓜、松茸不缺，seedW 没动。
3. 「能种的菜都 ≥ 80% 就先不种」、空地写原因：照旧。
- 游戏说明（温室种菜、员工种地）、「种菜」面板的「?」都改了。

- **目标达到了**：4、5 级「没人种」+「没种子」都 ≤ 10%（0.3% / 5.7% / 9.3% / 8.2%），所以 farmGap 3 → 2.5 秒没去试。
- 2、3 级空着多是「仓库快满」：地多、菜卖不完，正常。3 级比 50a 多一点，因为收完马上补种，菜更快攒到 80%。
- 3 级电池 1.27：之前几次 3 级也在 1.24～1.30 之间晃（回收机出的，跟种地无关），货柜没空过。
- 南瓜、松茸：仓库最低都没到 0。史诗那组南瓜最低 1，但货柜没空过。所以 seedW 没调。
- 种子：结束时每种只剩 0～几包，基本是「收一包、种一包」刚好够用。员工练高以后（史诗、传说）「没种子」7% 左右，比收种的人手先成为瓶颈。
