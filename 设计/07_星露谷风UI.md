# 07 星露谷风 UI（0.21）

用户 10-13 定：以后设计风格、UI 界面都参考星露谷。这一版选了三项：

| 项 | 做法 |
|---|---|
| 面板皮肤 | 暖色木框（像素图 img/ui/sv_panel.png，2 倍放大、不模糊）+ 米黄纸面 + 深棕字；里面的卡片是浅一档的纸面小框（sv_card.png）；按钮橙黄木色带下沿阴影；次要按钮米色 |
| 顶部状态栏 | 末日币、口碑、背包、任务、消息、菜单都换木牌底（sv_chip.png），奶白字 + 深棕描边 |
| 背包 | 上面一条「钱包」（末日币、发条、肥料、饵料、鱼竿，不占格子）；下面方格子（sv_slot.png），图标居中、数量右下角；选中的格子红框，名字和丢弃在下面那条里 |

一起换纸面的：确认框、消息下拉框、钓鱼选饵框、布置超市的提示框和按钮。
保持深色的：尸潮 HUD（打仗时看得清）、地图上的标签、提示条（toast）。

所有改动在 style.css 末尾「0.21 星露谷风」一段，颜色通过在面板上重设 --ink/--dim/--good 等变量完成，没有改布局和玩法。
