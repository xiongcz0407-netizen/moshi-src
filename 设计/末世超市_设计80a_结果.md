## 切图（tools/cut_refine.py → src/img/fb/ref_*.png）
| 图 | 做法 |
|---|---|
| 铁砧 `ref_anvil` | 从四周泛洪去白底，边缘羽化一点 |
| 大锤 `ref_hammer` | 同上，再**左右翻过来**：锤头在左上，柄尾在右下。这样锤子从装备右上方落下，转轴是柄尾 |
| 灰烟 `ref_smoke` | 按「离白多远」算透明：核心灰色不透明，边缘留软边；颜色从白底里除回来 |
| 火花 `ref_spark`、火星 `ref_ember` | 越白越透明（≈ 1 − 最暗通道 / 255）。被光包住的亮芯算不透明，不然中间是个洞 |
| 金光 `ref_burst` | 同上；中间一整片淡黄白，用从中心往外渐淡的圆当亮芯，不然是一块硬边的饼 |

## 动画（新文件 refinefx.js，整段只跟时间 t 有关，能跳、能停在某一刻）
1. **0～0.2 秒**
   - 炼宝页盖上暗底（80% 黑），中间出铁砧，装备图标放在上面。
   - 图标后面一圈品质颜色的光，一直轻轻呼吸。
2. **敲 3 下**（0.45、0.85、1.3 秒敲中）
   - 锤子以柄尾为轴转：落下 0.1 秒（加速），抬起 0.28 秒（减速）。
   - 敲中时：火花一张、小火星飞出去（带重力，朝飞的方向转）；铁砧和装备往下一顿；整个框震一下。
   - 第 3 下顿得、震得最重，火花最大，火星最多。
   - **升 9 星以上**：第 3 下推迟到 1.5 秒，前面停顿时锤子发金光、一闪一闪。
3. **出结果**（第 3 下后 0.1 秒）
   - **成功**
     - 金光爆发；装备放大再回弹，图标上的星数换成新的；
     - 大字「炼宝成功！」+「★ n 星」；
     - 几颗小星星往外散；一颗星星划弧线飞到右边星星那排第 n 颗，落下那颗亮起（pop）。
   - **传说成功**：金光更大（330 对 250），装备放得更大，散出的小星星 9 颗（平常 4 颗）。
   - **失败**
     - 灰烟冒起往上飘；装备左右抖、变灰 0.5 秒再恢复；
     - 大字「失败了」+「星星没掉」；
     - 4～8 星再加一行绿字「下次成功率 +5%（现在 75%）」，这个数是失败后的新成功率。
4. **收起**：结果放完停 0.6 秒，淡出，面板刷新成炼完的样子。整段 2.8 秒，9 星以上 3.0 秒。
5. **跳过**：画面右下角写「点一下跳过」。
   - 动画中点一下，直接跳到结果放完（星星已经亮了）；
   - 结果出来后再点一下，马上收起。
6. **防连点**
   - 动画放着时「炼宝」按钮是灰的；
   - 点在暗底上会被挡住；
   - 代码里也挡了：动画没完就不处理第二次炼宝。
7. **toast 去掉了**。

**要注意的一处**：点了按钮，面板会马上自己刷新一次（通用的按钮处理）。所以动画放着时，炼宝页照「炼之前」的样子画（星数、成功率、保底），等星星飞到了才换成真的，不会提前露出结果。星星那排在详情里被卷走时，会自动卷回来，星星才飞得过去。

## 测试（无头 Chrome，844 × 390 和 667 × 375；用 `__g.RFX.seek(t)` 停在某一刻截图）
| 测试 | 结果 |
|---|---|
| 成功（史诗 2 → 3 星） | 「炼宝成功！★ 3 星」，星星飞到第 3 颗 |
| 失败（史诗 5 → 6 星，成功率 70%） | 「失败了 / 星星没掉 / 下次成功率 +5%（现在 75%）」 |
| 9 星以上（套装 9 → 10 星） | 第 3 下在 1.5 秒，前面锤子发光；结果 1.6 秒出 |
| 传说成功（雷鸣 M16 3 → 4 星） | 金光更大，小星星更多 |
| 动画中连点 5 次（测试里先把灰按钮强行打开再点） | 晶石 500 → 498，只扣 1 次；星 1 → 2 |
| 0.5 秒时点一下 | 直接到结果；再点一下收起，面板还在炼宝页，按钮能点 |
| 正常放完 | 星星亮起，面板刷新，星数对 |

- 无头 Chrome 每秒只有几帧（每帧最多走 0.25 秒），所以测试里放完一段要 10 秒左右。动画按真实时间走，手机上就是 2.8 秒。
- lint 0 错误；fbtest 41 项通过；没有报错。
