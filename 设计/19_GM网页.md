# 19 GM 网页 —— 0.33（用户 10-15 定）

用户定的：
- 只放在用户电脑上：末世超市/GM/gm.html，双击用浏览器打开；不发布到 GitHub Pages。
- 列出云端所有玩家，点存档位「读取」，不用知道玩家口令。
- 能改：货币和道具、仓库商品、等级。
- 玩家在线就提示「改了会被覆盖」，不在线就不提示。

## 一、页面
- 顶上「刷新玩家列表」：每个玩家一行，3 个存档位各写摘要和保存时间，最近玩过的在上面。
- 读取后显示在线状态和三组数值：
  - 货币和道具：末日币、星星、发条、肥料、刷新卷、尸潮卷、鱼饵、宝物（工具箱等、树苗）、种子。
  - 仓库商品：每种商品；鱼按种类改（总数自动跟着算）。
  - 等级：按「级」算的建筑（超市、回收机、仓库、背包、温室、果园、鱼竿、池塘、宿舍楼、医院、6 个动物棚）、口碑、经验点、每个货柜的档次。货架 / 果蔬架 / 冰柜「建了几个」不能在这里改（要跟货柜摆放对得上）。
- 改过的格子变绿；「保存」前弹一次确认，列出每项「旧 → 新」。

## 二、在不在线
- 游戏开着时每分钟自动存一次；切后台记 bgAt，关游戏记 closedAt。
- 判断：关了游戏 →「不在线，放心改」；切到后台没关 → 黄色提示（切回游戏会覆盖）；3 分钟内存过档 → 红色「在线，改了会被覆盖」；更早 →「不在线」。
- 只提示，不拦：在线时保存，确认框里也会再提醒一次。

## 三、保存（安全）
- 保存前再读一次存档：读取后玩家又存过档的话，不保存，重新读出最新的让你再改。
- 先把原存档备份到 saves/gm_bak_时间_玩家_位.json，再写回去；存档位摘要（标题页那行）一起更新。
- 存档里记 gmAt（改的时间）和 gmNote（改了什么）。游戏读档时，gmAt 比手机里缓存的新，就用改过的；进游戏提示「存档被管理员修改过：……」。
- 离线收益照常按原来的时间算，改存档不会让玩家少算或多算离线时间。

## 四、令牌
- 和 game.js 一样，令牌只在用户电脑上填进 gm.html，不经过云端。gm.html 不要发给别人。
- 代码：tools/gm/gm.js、tools/gm/build.mjs（node tools/gm/build.mjs 输出文件 @INJECT）。
