# 设计84a：毒雾要有气体感、毒囊放技能时不变形、皮肤深一点 —— 结果（V6.91 → V7.01）

版本：**V7.01**（APP_V 701）。存档格式没变。
截图、视频：`美术/检查截图/1022_设计84/`

## 一、毒雾改成一团团会动的软雾（新文件 fbfog.js）
原来台地上的毒雾是平铺的贴图，用户说像绿地毯。81 的毒雾长条、上涌那半边的平铺贴图、崖边一排「毒雾墙」都去掉了，改成下面两样。

1. **雾团**
   - 很多张大团毒雾（fx_cloud）和毒雾丝（fx_wisp），一次画完（实例化，只占一次绘制）。
   - 每团大小 2.8～5.2 米、透明度 0.25～0.55、离地 0.25～2.5 米，都是随机的，叠出厚度。
   - 每团都在慢慢动：飘、转、一胀一缩、一明一暗，速度各不一样。
   - 软粒子：贴近台地地面、崖壁的地方自己淡掉，不会出现一刀切的底边。
2. **贴地雾**
   - 很淡，透明度不超过 0.35。
   - 边用两层噪声做遮罩，一直在起伏、往外渗，不是直线，也不是矩形。
   - 判定的那条线上留一条淡淡的红边。判定还是原来的矩形，没改。

### 毒雾上涌（视频 `84_毒雾上涌_全过程_8秒.mp4`）
| 阶段 | 现在的样子 |
|---|---|
| 预警 2 秒 | 那一侧崖边冒毒雾丝，越来越多（每秒 4 → 22 根）；最后 0.6 秒崖下开始往上冒大团的雾 |
| 涌上来 | 26 团大雾从崖边一团团翻上来、往场地里滚。近崖边的先到，远的后到，错开 0.3 秒左右，0.6 秒铺满半边。贴地雾的边跟着从崖边推到中线 |
| 停留 4 秒 | 雾团在那半边里慢慢飘、翻滚。崖边随机位置一直有 6～9 团往上冒再散开，大小、时间都不一样，底部在崖下面 |
| 退回去 | 判定结束后，雾一团团往崖边退、变淡，过了崖边就掉下去（0.4～1 秒）；贴地雾的边也退回崖边 |

- 退的时候判定已经没有了，所以画面上的雾只会比判定多，不会比判定少。

### 半血以后两边收进来（视频 `84_半血收边_6秒.mp4`）
- **收之前 3 秒**：崖边红线照旧，要收进来的那条里开始冒毒雾丝。
- **收的时候**：几团大雾从崖边慢慢爬进来（0.8～1.2 秒）；贴地雾的边在 1.2 秒里一点点推进去，边一直在起伏。
- **收完以后**：
  - 那一条一直有 9～12 团雾在翻滚；
  - 每 0.4～0.8 秒往上冒一根丝；
  - 每 2～4 秒有一团往里飘大约 1 米再散掉。
- **顺便修了 81 的一个问题**：以前收边时，崖边红线、毒雾长条读的是开场时的场地。现在读的是每打一次重新建的场地，第 2 次进副本也对。

### 数量和手机帧数
- 台地上同时最多 40 团，其中毒雾丝最多 12 根。不够的时候，先让掉预警时冒的丝。
- 每 2 秒看一次帧数：
  - 掉到 45 以下：上限降到 30 → 20，每团按比例画大一点；
  - 回到 55 以上 6 秒：再加回来。
- 测试里用 `window.__fogQ = 1` 固定不降。
- **请在手机上开性能小窗看一下**：上涌和收边叠在一起的时候，帧数够不够。

## 二、毒囊放技能时变形
动作在 Blender 里重新做了一遍（tools/toxic_rig：rigbuild.py、anim.py、run84.sh）。toxic.glb 重新导出，大小 517 KB，跟原来差不多。

### 1. 头陷进肩膀里
仰头改成「脖子往前上方伸、头往后仰一点」，加起来不超过 20°；肩膀几乎不抬。

| 动作 | 头最多往后仰（改前 → 改后） | 肩膀最多转（改前 → 改后） |
|---|---|---|
| 毒雾上涌 | 43° → 17° | 12° → 5° |
| 狂暴 | 44° → 20° | — |
| 毒囊爆裂 | 46° → 16°（原来「缩头」那一下也收了） | 8° → 3° |
| 拍地收手 | 往前俯 31° → 12° | 16° → 5° |

- 用游戏镜头的角度看，6 帧里脸都看得到。
- 酸液喷吐、毒弹、受击、倒下按文档没改。

### 2. 举起的手变成深褐色的「橡胶手套」
- **原因**：不是法线，是贴图。贴图里手臂内侧、手心那几块本来就是褐色、没有细节（放下时看不到）。手一举起来就露出来了，加上背着太阳，就是一片深褐色。
- **改法**：着色器里只改手臂那一段（模型上离身体中线 0.2 以外）：
  - 褐色的地方换成跟身上一样的灰绿色，明暗照留；
  - 朝着镜头的面补一点光。
- 现在举起来的手跟身体一个颜色。

### 3. 脓包被拉成长条、前臂变细
- 先把模型上重复的点合并了。原来皮肤是碎成好几块拼起来的，各块权重不一样，一动就会裂开。
- 肩膀、腋下、手肘一带的权重做了 14 次平滑。
- 手臂抬高收到 60° 以内：
  - 拍地：74° → 60°，改成往前上方举，正面看到的是手背；
  - 上涌：57° → 40°。
- 看修前修后对比图，脓包还是圆的，前臂没有变细。

## 二b、皮肤深一点
- 着色器里给皮肤乘一个颜色（线性空间 0.44, 0.52, 0.34），贴图本身不动。
- 同一个镜头测：亮度 0.396 → 0.323（−18%，这里连脓包一起算了），饱和度 0.20 → 0.28，色相 69° → 76°，偏橄榄绿。
- 脓包、滴液的黄绿发光不动，皮肤深了以后更显眼；眼睛的光也不动。
- 腰下面那截沉在雾里的身子跟着调深。
- **头像 boss_2**：同样的算法调深，脓包、眼睛不动。副本面板和战斗里用的是同一张。
- **备份**：原来的头像、81 版 toxic.glb 都放在 `美术/备份_设计84/`。

## 三、其他
- **大招眼睛变红**
  - 原来改了颜色，但发光是叠加的：红色叠在绿皮肤、绿雾上会变成黄色，所以看起来还是黄的。
  - 现在大招、狂暴时多一颗正常颜色的红眼珠，不会被雾盖住。截图里一眼看得出：
    - `84_上涌_眼睛变红_仰头吼`
    - `84_狂暴_眼睛变红`
- **毒囊爆裂飞出去的脓包**
  - 原来是飞的时候光晕太大，把脓包模型盖住了，看起来像一团云。
  - 现在飞的时候不带光晕，只有模型和往下滴的液；落地以后光晕才慢慢亮。
  - 截图：`84_爆裂_脓包在天上飞`、`84_爆裂_脓包落地`。
- **超市飘字**
  - 打副本时，超市那边的飘字（「+1 罐头」「3倍！」、收银「+$」、员工收菜等）都不显示了，屠夫关也一样。
  - 「变宝！」「暴击 ×10」的大字照旧会出。
  - 实测：在副本里假装回收机出 3 倍罐头，飘字 0 个。
- **镜头**：46° 先不动，等你在手机上看。
